# REPORTS

One file per finished task: `<date>-<agent-id>-<task-id>.md`. Each report MUST
open with its own `author_llm: <name> (<version>)` line. Record: scope touched,
commands run (`compile.bat/sh`, `javac -version`), result, and files changed.
Reports are observations — no authority; `TASK_LEDGER.md` + `docs/DECISIONS.md`
carry the record.
