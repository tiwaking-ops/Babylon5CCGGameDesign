## What changed

The old block rendered only `Winner: <name>` or `Winner: None`. The new block:

1. Queries `VictoryPathResult vpr = rules.checkVictoryPath(state)`.
2. On a non-null path, renders `GAME OVER — <PATH> win | Power: N | <qualifier>` where the qualifier is path-specific:
   - `LAST_STANDING` → Remaining: N (always 1)
   - `STATION_CONDITION_2` → Station: N
   - `AGENDA_CONDITION` → Agenda: <winConditionKey>
   - `MAJOR` → Lead: N
   - `STANDARD` → Lead: N
3. On a null path (no winner, per B5-0663's null-path contract), renders `GAME OVER — No winner` explicitly instead of the old `Winner: None` string.
4. Keeps the existing `passButton.setEnabled(false)` / `playCardOnlyButton.setEnabled(false)` / `initiateConflictButton.setEnabled(false)` disablement unchanged — not this row's business.
