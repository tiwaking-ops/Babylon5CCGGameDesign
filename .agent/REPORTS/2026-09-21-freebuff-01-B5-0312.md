# B5-0312 — scenario playtest report

Agent: `freebuff-01`. Toolchain: `javac 1.8.0_292`. **No source edits** — the
ledger's execution-only constraint was honored; behavioral data came from a
throwaway runner compiled into the git-ignored `b5ccg/out/` scratch area
(B5-0204/B5-0307 precedent), deleted after the runs.

## Method

- **10× `HeadlessSmokeTest`** (each run an independent sample: the AI's
  `Random` is unseeded and the harnesses take no seed argument — noted as
  this task's interpretation of "across seeds"; changing that would require
  source edits, which this task forbids).
- **3× 8-round playtest** via the scratch runner: same setup as the smoke
  test (4 all-AI players, 60-card decks from own-faction + ANY/NEUTRAL/
  NON_ALIGNED file-order fillers), but runs 8 rounds and dumps the full
  game log + end state, so conflict/outcome lines can be mined.
- **3× `HeadlessConformanceTest`** through `RUN_TESTS=1` runs during B5-0309
  close-out (45/45 each time).

## Headline finding: the smoke scenario structurally cannot produce a conflict

Across **24 rounds of play** (3 runs × 8 rounds) there were **zero
conflicts, zero Build Influence actions, zero damage events, zero aftermaths,
and zero agenda plays** (192 total actions: 105 PASS, 70 RECRUIT_CHARACTER,
17 PLAY_CARD).

Root cause, verified against `b5ccg/resources/cards/`:
1. **All 108 conflict cards are `faction: ANY`.**
2. The smoke deck builder takes own-faction cards (35–41 per faction) plus
   the first ~20 filler cards **in file order**.
3. In file order, the first conflict card sits at **filler position #42**
   (positions #42–53+), so it never makes a 60-card deck.

Consequences: the AI never offers INITIATE_CONFLICT (no conflict card in
hand), B5-0309's support/opposition win rule, aftermath play (D1/D3),
conflict loser penalties (D15/CardEffects), and the damage rule are all
**exercised only by the conformance suite, never by the harness scenario**.
The same file-order mechanism also explains zero agenda plays in runs 1–2
(though 34 of 46 agendas are ANY, their file positions mostly fall beyond
the cut; the 12 faction-owned agendas are only reachable for their own
faction).

## AI balance observations (8 rounds, all-AI)

- **Zero variance in harness structure, some variance in outcome.** All
  10 smoke runs: 8 AI actions, 13 callbacks, 4.82–5.11 s, exit 0. The
  action count is deterministic by structure (each player takes their 1
  action then passes; all-pass ends the round). Card *choices* varied.
- **Influence gap is AI-personality-driven.** End states ranged from flat
  (all 4 influence, run 1) to run 3: Alpha (EASY) 20, Gamma (HARD) 20,
  Beta (MEDIUM) 4, Delta (MEDIUM) 4. Growth comes almost entirely from
  PLAY_CARD effects (locations/agendas in hand) and occasional events, not
  from conflicts.
- **The 20–20 tie actually held the line** — run 3 ended with two players
  at 20 influence and *no winner*, exactly what B5-0305's strictly-greatest
  rule requires. But see the stall risk below.
- **Ambassadors are untouchable in practice**: with no conflicts, the
  military-damage rule and aftermath effects never fire.

## Stability: zero flakes

- 10/10 smoke runs exit 0, zero exceptions, zero timeouts
  (`ROUND_TIMEOUT_MS` never approached), deterministic 4820–5108 ms wall
  time (dominated by the fixed 600 ms AI decision pacing).
- 3/3 8-round playtests exit 0, 38.5–39.1 s, no game-loop errors.
- Conformance suite: 45/45 PASS every invocation.

## Risks / recommendations for follow-up tasks (NOT applied)

1. **Scenario coverage gap (test-side, needs a task).** A deck-construction
   tweak in the smoke harness — shuffle the filler pool, or guarantee a
   quota of conflict/agenda cards per deck — would make the scenario
   exercise the conflict pipeline end to end. This is a harness-only change
   (B5-0201's file, engine/ test area), no game-logic edits.
2. **Victory stall risk (rulebook-ambiguous edge, needs a task).** With
   major agendas absent and D12's tie rule blocking both players, a 20–20
   tie at zero-conflict spread means nobody can ever win unless another
   player breaks the tie; in run 3 the 8-round window just ended there. A
   tiebreak or dynamic agenda point becomes relevant for long games.
3. **AI perception gap.** With conflicts absent from decks, MEDIUM/HARD
   scoring paths for INITIATE_CONFLICT and aftermath evaluation are dead
   code in practice; once decks carry conflicts, the B5-0202 finding about
   influence-cost scoring (Finding 6) will matter immediately.
4. **Build Influence needs Inner Circle.** `AIPlayer` offers it whenever an
   IC character is unrotated, but nothing ever promotes a recruit to Inner
   Circle (B5-0202 Finding 7, cross-scope), and ambassadors don't count —
   so the action is currently unreachable in play, and influence growth
   relies entirely on card effects.
