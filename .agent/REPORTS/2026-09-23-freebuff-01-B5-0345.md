# B5-0345 — F3 remainder: every still-unreachable §V action, ranked by engine cost

Report-only task: no `src/` or `resources/` edits. The B5-0310 audit (F3,
P0/HIGH) listed 14 Action-round action types the UI cannot reach; several have
since become reachable in the engine (B5-0321/0323/0324/0328, B5-0336–0340,
B5-0343). This report re-audits reachability **at the engine level** as of
2026-09-23 and ranks the remainders into sliced, independently landable
implementation tasks.

Method: rulebook §V "Action Details" (normative text, lines 647–741) is the
inventory; the code map comes from `GameController.buildLegalActions` /
action handlers, `AIPlayer.buildLegalActions`/scoring, `RulesEngine`
primitives, and the model classes, all read this session.

## 2. Ranking by engine cost, with task slicing

**Tier 1 — thin slices (engine primitives already exist; one small task each).**

1. **Lead-a-Fleet slice.** Add `GameAction.Type.LEAD_FLEET`, offer it in both
   builders for legal `(own ready character with Leadership, own unrotated
   fleet)` pairs, one controller handler calling `executeLeadFleet`, suite
   section. The B5-0337 seam was built for exactly this. Est. effort: the
   smallest of the set.
2. **Human support/oppose join control.** Engine needs nothing; the join loop
   and side semantics are live (B5-0343). Belongs with the ui/ band (a
   participant list + join button), not an engine task.
3. **Agenda lifecycle actions.** New types (`DISCARD_AGENDA`,
   `REPLACE_AGENDA`, `REVEAL_AGENDA`) + engine enforcement of the rulebook's
   major-agenda guard ("cannot discard a Major; can only replace with another
   Major") in `setAgenda`/a `canReplaceAgenda` seam + optional hidden-agenda
   face-down state. Sponsor-agenda legality (one-major rule) should be
   enforced here too, regardless of the concurrent B5-0344 AI-side gate.

**Tier 2 — new model + action (self-contained).**

4. **Contingency cards.** New `ContingencyCard` model class, face-down-under-
   host placement (a `placedUnder` link), reveal trigger surface. Parity with
   event play afterwards. No dependency on other slices.
5. **Generic rotate-for-effect action.** Promote the assistant boost (B5-0339)
   and future Vir-style effects into a real `USE_ROTATE_EFFECT` action with a
   target list; engine-first, UI second. Depends on nothing; interacts with
   B5-0357's bonus-layer proposal for the effect payloads.

**Tier 3 — damage subsystem first (prerequisite for three actions).**

6. **Damage & neutralization model** (the gating slice): per-card damage
   counters, ability reduction (floor 0), neutralization at ≥ greatest
   ability, severe-damage overflow, neutralized-card action lockout,
   fleet-leader auto-neutralization (§V "The Effects of Damage"). Should be
   designed together with B5-0357 (bonus layer) so damage reduction composes
   with expiring bonuses instead of fighting them. Note: `Conflict` damage
   from B5-0309 (ambassador damage on a ≥3 military gap) is conflict-scoped
   state, not the per-card ledger §V needs.
7. **Attack a Conflict Participant** (needs 6): mutual damage = current
   ability, Strife marks +2, attacker/target participation rules (same
   ability, not own faction, not neutralized, fleet-leader exclusion).
8. **Heal + Repair actions** (needs 6): rotate-to-clear-damage; repair spends
   1 influence per token (the first *per-token* influence spend — D9/B5-0342's
   applied-pool design should be in place first or will need retrofit).

**Tier 4 — new phase + data.**

9. **Mercenary offers** (deepest): bid state per player, cumulative bids,
   control resolution, a post-pass/pre-Resolution mercenary phase, plus the
   card-data identification of mercenaries (gate: B5-0355's text-authenticity
   audit).

## 3. Ordering constraints recorded for the overseer

- Tier 1.1 (lead-a-fleet) and Tier 2 items are **independent** of D6/D9 and
  can land on today's one-action loop.
- Tier 3.8 (repair) spends influence per token: it inherits the B5-0342 (D9)
  ordering dependency — pool semantics first, or the repair spend permanently
  erodes Rating exactly like Build Influence does today.
- The D6 (B5-0341) eligibility-loop rework should not be done twice: if D6+D9
  are imminent, land Tier 3/4 actions after them; Tier 1/2 slices are safe
  either way.
- The B5-0344 AI work currently in flight offers aftermath-hold and agenda
  gates at the AI layer; the engine-side agenda legality this report assigns
  to Tier 1.3 would supersede those AI-side gates (keep both until then).
