# B5-0103 report — ui/ + util/ + Main.java Java 6 conversion

**Date:** 2026-09-21  
**Agent:** Solar Pro4 (solar-pro4:free)  
**Task:** B5-0103 — Convert `ui/` + `util/` + `Main.java` to Java 6

## Toolchain

- `javac -version`: `1.8.0_292`
- Build gate: `javac -source 6 -target 6`, stdlib only

## Scope note

The `ui/` portion of this task was already Java 6-clean from B5-0001 (which
fixed lambdas, method refs, and diamonds in `MainWindow.java`, `HandPanel.java`,
and `GameBoardPanel.java`). No further `ui/` work was needed.

## Files touched

### util/ImageCache.java

- `cache.computeIfAbsent(key, ImageCache::load)` → manual check-then-put
  (get existing or load+put). Both the `computeIfAbsent` method and the
  `ImageCache::load` method reference are Java 8+.
- `new ConcurrentHashMap<>()` → `new ConcurrentHashMap<String, ImageIcon>()`
- `new ArrayList<>()` → `new ArrayList<String>()` in `wrap()`

### Main.java

- `SwingUtilities.invokeLater(() -> { ... })` → anonymous `Runnable` inner class
- `new GameController(state, aiPlayers, gs -> { ... })` → anonymous
  `GameStateCallback` inner class (using the interface from `GameController.java`)
- `new Thread(controller::runGame, "GameLoop")` → `new Thread(new Runnable() {
  run() { fController.runGame(); } }, "GameLoop")`. Java 6 requires local
  variables captured by inner classes to be `final`, so added
  `final GameController fController = controller;`
- `new ArrayList<>()` → `new ArrayList<Faction>()` / `new ArrayList<Card>()`
  (3 occurrences in `otherFactions`, `buildFactionDeck`, `buildMinimalTestSet`)

## Files NOT touched

All `ui/*.java` files (already clean from B5-0001). `GameController.java`
already defines the `GameStateCallback` interface.

## Java 6-specific pitfalls resolved

- **Inner-class final capture**: Java 6 requires any local variable accessed
  from an inner class to be `final`. `Main.startGame()` now declares
  `final GameController fController = controller;` and the `Runnable` passed
  to `new Thread(...)` closes over `fController`.
- **`ConcurrentHashMap.computeIfAbsent`**: Java 8+. Replaced with the
  equivalent check-then-act pattern in `getCardImage()`.
- **Method references** (`ImageCache::load`, `controller::runGame`): Java 8+.
  Replaced with anonymous inner classes.
