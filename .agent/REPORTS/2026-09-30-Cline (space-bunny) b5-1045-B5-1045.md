### Design, and the one deviation recorded

The delta is a **restriction**, not a magnitude, so it could not go in any of
the existing `Map<String,Integer>` dispatch tables. I added a dedicated
id-keyed `Set` (`AGENDA_BANS_DIPLOMACY_AFTERMATH`) plus three predicates in
`CardEffects`, and one guard in the play gate `RulesEngine.canPlayAftermath`.

**Deviation from the row's letter, recorded rather than taken silently:** the
row said "extend the CardEffects agenda dispatch". A restriction that is never
read by the play gate is exactly the B5-0741 prose-effect failure the repo
keeps re-discovering, so the guard had to land in `RulesEngine.canPlayAftermath`
— same `engine/` scope, no ai/ui/data touched. The scope column's `engine/
CardEffects plus one conformance section` is honoured in substance and stretched
by one file in the same package; flagging it rather than shipping a predicate
nothing calls.

**Premiere-unchanged is structural, not a second branch.** `agenda_total_war`
is simply *absent* from the deluxe-only set, so the premiere path returns false
from the new predicate by table membership. There is no code that could
regress it, which is the property the row actually asked for.

**Scope of the restriction, stated explicitly:** only the Agenda's **owner** is
barred (TW-C5), a face-down agenda does not bind until revealed (TW-C6, the
B5-0364 rule already used by `applyAgendaStartOfRound`), and non-Diplomacy
Aftermaths are untouched (TW-C4).

**"Diplomacy Aftermath" is read off the existing trigger vocabulary**, not
invented: `AftermathCard.getTriggerCondition().contains("DIPLOMACY")`, the same
token test `AftermathCard.isEligible` already uses. Measured in the data: 6
records per set (`DIPLOMACY_PARTICIPANT`, `WON_DIPLOMACY`, `LOST_DIPLOMACY`).

**Deliberately NOT done, named so it is not mistaken for an omission:** the
core *"may not play Diplomacy conflict cards"* half is unenforced in the engine.
B5-1032 says so explicitly. Enforcing it would change premiere behaviour, which
this row forbids, so it stays unenforced.
