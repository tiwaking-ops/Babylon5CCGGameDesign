## Files touched

### engine/DeckLoader.java

- `try (InputStream is = url.openStream())` → try/finally with explicit `is.close()`
  in a `finally` block (Java 6 has no try-with-resources)
- 5× `new ArrayList<>()` / `new LinkedHashMap<>()` → explicit type args

- `import java.util.function.Consumer` → removed

- `aiPlayers.stream().filter(ai -> ai.getPlayer() == p).findFirst().orElse(...)`
  → for-loop in `getAI(Player)`
- `new ArrayList<>(p.getHand())` → `new ArrayList<Card>(p.getHand())`

### engine/RulesEngine.java

### ai/AIPlayer.java
