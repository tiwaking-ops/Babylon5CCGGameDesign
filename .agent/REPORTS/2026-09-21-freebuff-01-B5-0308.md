# B5-0308 — rulebook-conformance suite (headless)

Agent: `freebuff-01`. Toolchain: `javac 1.8.0_292`. Scope: **new test file
only** in `engine/` (B5-0201 precedent) — no game-logic file was touched.

## What was added

`b5ccg/src/b5ccg/engine/HeadlessConformanceTest.java` (~250 lines): asserts
each rule that was *fixed* from the B5-0203 audit directly against the
engine/model API, one named check per rule so a regression fails the build
with the rule's id. Conventions match `HeadlessSmokeTest` (stdout reporting,
exit 0/1).

* **D1 — initiator-perspective aftermath Won/Lost** (rulebook: Aftermath
  Cards / Aftermath Example): 8 checks — `initiatorWon` false/true; losing
  initiator blocked from WON, allowed LOST; winning opposer still evaluated
  against the initiator's outcome (regression guard against the pre-B5-0204
  behaviour); winning initiator allowed WON, blocked LOST.
* **D3 — aftermath conflict-type gating incl. PSI branch** (rulebook: Type of
  Conflict): 8 checks — PSI aftermath illegal on MILITARY/DIPLOMACY/INTRIGUE,
  legal on PSI; compound `MILITARY_PARTICIPANT` gating (type+participation);
  one check through the engine path (`RulesEngine.canPlayAftermath`).
* **D8 — deck-out penalty** (rulebook: Draw Round, Step 3): 5 checks —
  single penalty discards the non-ambassador IC character to the discard
  pile; next empty-pile draw flags forfeit with the ambassador intact; empty
  deck from the start flags forfeit; `checkVictory` returns the last standing
  player / null when nobody has forfeited.

## Skip policy (the "tie-break victory" clause of the task)

(NON_ALIGNED playability) are **still OPEN under B5-0305** — asserting them

(partially addressed by B5-0307). The moment B5-0305 lands, its owner should
replace those SKIPs with real checks — the file is structured for that.

ai/ in scope, so no engine game-logic change (which a D12 fix would require)
was made in this task.
