## FLAG 1 (structural, the one real defect): section 4's controls table is corrupted

The hunk replacing the **Attack** row produces three defects in the Markdown table:

1. The replacement line begins `+|| **Attack** | …` — a **leading empty cell**
   (double pipe), shifting the Attack row's columns by one relative to every other
   row. This is the ledger's own double-lead defect class (B5-0568/B5-0611), appeared
   in a guide table.
2. Two orphan `+||` rows follow it — empty table fragments.
3. The new `> **Board readout — Civil War state…**` blockquote is inserted **between
   table rows** (between Attack and Heal), which splits the controls table into two
   fragments in most Markdown renderers — the blockquote ends the table, so the Heal/
   Repair/Bid rows that follow render as a separate headerless table.

The row's own body text (the B5-0715 board-readout prose) is factually correct and
honestly caveated — the defect is purely structural placement. The repair is a
one-hunk guide edit; this row explicitly does not edit the guide, and no live claim
owns a guide repair, so it is flagged here for the next docs row.
