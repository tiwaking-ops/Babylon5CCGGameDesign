## What was done

**Fix (2 files, ~10 lines net):**

1. `b5ccg/src/b5ccg/model/FleetCard.java` — the floor pass (`int floored` + the `for (StatBonus b : owner.getBonuses())` loop) is now hoisted INSIDE the existing owner guard. Comment cites B5-0486 + B5-0494 + the finding. `getGreatestAbility()` audited in the same pass: it never dereferences `owner` unguarded (the 0486 edit did not touch it) — no change needed.
2. `b5ccg/src/b5ccg/engine/HeadlessLeadFleetScenarioProbe.java` — one new fixture assertion pinning the crash class: an owner-less `FleetCard` ("Orphan Fleet", no `setOwner` call) reads `getEffectiveMilitary() == 2` and `getGreatestAbility() == 2` with no registry access and no crash. Probe grows 8 → 9 checks.
