# B5-0329: Conflict-type legend (F9) + Assistant status readout (F10)

## Summary

Added two UI readouts to MainWindow/GameBoardPanel per the B5-0310 audit findings F9 and F10.

## F9: Conflict-type → ability legend

**Problem (B5-0310):** No legend mapping conflict types to abilities. A human player cannot tell that Military conflict is resolved with Military ability without memorizing the rulebook.

**Implementation (`MainWindow.java` constructor, right sidebar):**

Added a `JPanel` with `GridLayout(4, 2)` titled "Conflict Types → Abilities" below the game log scroll pane in the right sidebar. Four rows:

| Conflict Type | Resolving Ability |
|---------------|-------------------|
| DIPLOMACY | Diplomacy |
| INTRIGUE | Intrigue |
| MILITARY | Military (Fleets) |
| PSI | Psi |

The legend is a static info panel — no state-dependent updates needed.

## F10: Assistant status readout

**Problem (B5-0310):** No UI indication of whether the assistant is rotated and which +1 bonus it provides. The rotated orange border on mini-cards (existing art) is easy to miss during play.

**Implementation (`GameBoardPanel.java paintComponent`, conflict banner area + `MainWindow.java` constructor):**

Two-part implementation:

1. **GameBoardPanel overlay:** Added a text overlay in the upper-right corner of the game board during active conflict, listing all 5 assistant role descriptions from the design doc (Ambassador, Lokai-Commander, Refer-Consultant, Strategy-Analyst, Sanction-Interpreter) with their B5-0325 feature cross-references.

2. **MainWindow right sidebar:** Added an "Assistant Status" titled label (below the F9 legend) that is dynamically updated in `refresh()`:
   - Finds the human player from `state.getPlayers()`
   - Reads the first Inner Circle character as the assistant
   - Displays: `Assistant: <title> — rotated (+1 <ability>)` when rotated
   - Displays: `Assistant: <title> — not rotated` when not rotated
   - Displays: `Assistant: —` when no assistant is present

The assistant's rotated state and primary stat drive the +1 bonus display per B5-0310 §Assistant seat.
