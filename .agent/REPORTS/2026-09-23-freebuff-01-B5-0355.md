# B5-0355 — Text-authenticity audit

## Method

- **Data under audit:** `b5ccg/resources/cards/premiere.json` (446 records).
- **Reference:** SNRPG deckbuilder table (`saturdaynightrpg.co.uk`,
  `?pageName=Cardgames&type=B5CCG&var=B5CCG`) — one polite fetch with a
  descriptive User-Agent, same source B5-0335 used. 1729 data rows parsed
  (matches the B5-0335 census exactly). Schema per the pilot:
  KeyID/Name/Rarity/Type/SubType/Diplomacy/Intrigue/Psi/Leadership/Military/
  Cost/BoldText/EffectsText/…/FlavorText/Set/Race.
- **Anchor validation first:** KeyID 33 Adira Tyree D/I/P/L=(0,3,0,0) cost 5
  and KeyID 416 Du'Nar (7,4,0,4) cost 11 — both reproduce the 2026-09-22
  scan ground truth from `docs/reports/ccgtrader-2card-pilot-2026-09-22.md`
  (`scanOK=True` for both). The reference is trustworthy for this audit.
- **Join:** normalized-title exact match pool→DB. **439/446 matched (98.4%);**
  7 unmatched (see §4). Where a DB title has multiple reprint rows, the pool
  was credited if it matched **any** variant row (stat_match = membership of
  the pool's D/I/P/L tuple in the DB's variant tuples).
- **Similarity:** word-set Jaccard between the pool `text` and DB
  BoldText+EffectsText (normalized, best DB row per title).
- **Read-only guarantee:** analysis scripts and intermediate artifacts were
  kept outside the repo (`C:/temp/projects/tmp/`, deleted afterwards). Zero
  bytes written into `b5ccg/resources/`, `b5ccg/src/`, or governance code.

## 1. Headline verdict

**The pool's game texts and character stats are a deliberate design-layer,
not an authentic transcription — and B5-0335's cost-only backfill remains
exactly that: cost-only. Verified empirically: no stat or text value changed
during backfill; every pre-existing value is byte-identical before/after.**

- **Stats:** 352/439 title-matched records (80.2%) have D/I/P/L identical to
  the DB — but **every single one is a vacuous all-zeros match** (cards whose
  type prints no stat bubbles: AFTERMATH, AGENDA, CONFLICT, ENHANCEMENT,
  EVENT, FLEET+GROUP+LOCATION zero-stat rows). Among the 87 title-matched
  CHARACTERS: **0/87 match**.
- **Texts:** **0 of 439** pool texts are identical to the corresponding DB
  game text (normalized); **438/439 have Jaccard < 0.5**. This is a
  paraphrase layer, not OCR noise.

## 2. Character stat mismatches (the material finding)

All 87 title-matched CHARACTERS differ from the printed DB row. Pattern:
the pool's stat assignments are a **game-design artifact** (plausibly
LCG-style balance), not card-accurate data. Examples (pool D/I/P/L vs DB):

| Card | Pool | DB/scan |
|---|---|---|
| Adira Tyree | 3/4/0/1 | **0/3/0/0** (scan-confirmed) |
| Du'Nar | 2/4/0/2 | **7/4/0/4** (scan-confirmed) |
| G'Kar | 4/5/0/3 | (5/1/0/3) KeyID 566 ambassador variant |
| Delenn | 7/3/2/5 | (6/0/0/3) KeyID 348 ambassador variant |
| Londo Mollari | 5/6/0/4 | (4/4/0/0) KeyID 820 ambassador variant |
| Jeffrey Sinclair | 5/3/0/4 | (4/0/0/3) KeyID 731 ambassador variant |
| Centauri Agent | 1/2/0/1 | (0/3/0/0) |
| Emperor Turhan | 6/3/0/4 | (9/3/0/0) |

The four big-name ambassados are structurally different from every DB row
(they are pool-unique designs, not any single printed version).

## 3. Text authenticity

- **0/439 verbatim, 438/439 Jaccard < 0.5** — the pool's texts are a
  distinct design layer, not transcriptions.
- Structure visible in the divergence: pool texts are **short paraphrases
  optimized for engine consumption** (short imperative "Win Condition:",
  "Inner Circle", "Gain 1 Influence" hook tokens; B5-0352 added
  machine-readable participation objects on top).
- Engine-hook census over pool texts: `Inner Circle` ×77, `Gain 1 Influence`
  ×28, `Win Condition` ×26, `Psi` ×21, `Ambassador` ×11, `Aftermath` ×6.
  Texts are load-bearing for the engine and are not a safe overwrite target.
- **IP-risk outlier:** `group_commercial_telepaths` matches the DB game text
  at **96% word overlap** — the only card that reads like a transcription of
  copyrighted text. 171 further cards sit in the 26–50% overlap band
  (short-text coincidences and shared rule vocabulary), none individually
  alarming, but the Telepaths card alone is worth a deliberate rewrite
  decision by the data owner.

## 4. Join failures (7 records)

Six characters have no DB title match (all are "pool-unique name" cases):
Jeffrey Sinclair, G'Kar, Delenn, Londo Mollari, Zack Allen, plus
`enh_judgment_by_success` / `event_level_the_playing_field` with DB spelling
variants ("Judgement", and "Level the Playing Field" without the pool's
own "3+9" suffix). Fuzzy matches exist for all but Zack — whose DB row is
**"Zack Allan"** (KeyID 1720; pool title "Zack Allen" is a **canon spelling
typo** in the pool). The four ambassados exist in the DB only as
reprint variants ("(ambassador)" rows) that we cannot uniquely join by
title alone. This is a **record-keeping item for the task row**, not a
defect in B5-0335's work.

## 5. Answer to the row's question

- **Cost-only backfill is safe and was done safely.** Empirical
  HEAD↔working-tree compare of `premiere.json`: 446 records, same IDs, zero
  changed stat/text values; the only differences are *added* keys —
  `cost` ×209 (B5-0335) and `participation` ×5 (B5-0352). Additionally,
  all 209 backfilled costs agree with the SNRPG reference on unambiguous
  title joins (**209 agree / 0 disagree**) — a consistency confirmation of
  the backfill (not independent proof of printed accuracy; scans remain the
  authority, and both scan anchors match). Cost-only stays the correct
  separable step.
- **Text/stats overwrite is NOT safe today** and would be a deliberate
  design-layer replacement, not a correction. If authentic printed values
  are ever adopted wholesale, that is a **new dedicated data task** (all 87
  character stat blocks + ~439 texts rewritten + engine hook regression
  suite re-run) — not a backfill. The SNRPG DB can supply it (plus 3
  unreferenced costless characters now resolvable: Kosh Naranek=1,
  Ambassador Kosh=4, Zack Allan=6), but the engine-hook vocabulary would
  need porting first. (DB costs already recovered for three of the six
  title-unmatched characters: Zack Allan=6, Ambassador Kosh=4,
  Kosh Naranek=1 — usable only via that future task.)
- **Recommended (low-risk) hygiene items only:** fix the "Zack Allen" →
  "Zack Allan" title typo, rewrite Commercial Telepaths' text to an
  IP-safe paraphrase, and keep the ambassados/Kosh as pool-unique designs
  unless/until a full authenticity migration task is seeded.
