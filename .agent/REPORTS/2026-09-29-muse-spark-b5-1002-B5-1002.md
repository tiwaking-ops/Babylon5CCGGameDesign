# B5-1002 report (muse-spark-b5-1002, 2026-09-29)

## Task
Make the census and queue tools read explicit UTF-8 and emit which encoding
they read, closing the phantom-defect trap (DECISIONS.md measured 1600 C1
naive vs 0 UTF-8 on the same bytes).

## Phantom reproduced (PowerShell-native, same bytes)
- `docs/DECISIONS.md`: `(Get-Content -Raw)` = 1600 C1 marks;
  `[IO.File]::ReadAllText(path, UTF8)` = 0. Exact seeded figures.
- `.agent/TASK_LEDGER.md`: naive = 146, UTF-8 = 143 across 77 lines
  (seeded 143/77 reproduced).
- Mechanism: both files are BOM-less UTF-8. `Get-Content` without `-Encoding`
  sniffs for a BOM, finds none, falls back to host ANSI, and ANSI-decodes the
  multi-byte sequences into phantom C1 controls. A file written *with* a BOM
  reads identically under both instruments -- verified with a synthetic
  fixture -- which is why spot-checks on the wrong files never catch this.

## Changes (idiom-preserving, additive only)
- `Get-Content ...` -> `Get-Content ... -Encoding UTF8`.
- `ReadAllLines(p)` -> `ReadAllLines(p, [Text.Encoding]::UTF8)`;
  `ReadAllText(p)` -> `ReadAllText(p, [Text.Encoding]::UTF8)`;
  `Select-String -Path` -> `Select-String -Path -Encoding UTF8`.
- Receipts: stdout footer/header/banner in run-queue, ledger-query,
  census-crosscheck, validate-heartbeats, suite-coverage, run-dup-census;
  `Write-Verbose` in dup-census because its stdout must stay empty on pass by
  contract (the wrapper re-prints every stdout line as a duplicate ID, and
  00_BOOT step 9 reads empty output as pass).
- NOT changed: exit codes, TTL, liveness rules, verdicts, statuses, heartbeat
  filenames, agent ids. No `b5ccg/src`, card-data, commit or push.

## Reusable lesson
A count whose instrument is unnamed cannot be reproduced -- name the decoding
in the output, not just in the code.
