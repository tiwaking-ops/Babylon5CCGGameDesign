# B5-0001 report — MainWindow init fix

**Date:** 2026-09-21  
**Agent:** Solar Pro4 (solar-pro4:free)  
**Task:** B5-0001 — Fix MainWindow init (statusLabel/playCardButton might not have been initialized)

## Toolchain

- `javac -version`: `1.8.0_292`
- Build gate: `b5ccg/compile.sh` (`javac -source 6 -target 6`, stdlib only)

## Problem

`MainWindow.java` lines 36-40 captured `statusLabel` and `playCardButton` in a lambda (`setOnCardSelected`) **before** those fields were initialized at lines 61/66. The Java compiler flags: "variable statusLabel/playCardButton might not have been initialized". This fails even at `-source 8` — a pre-existing fault, not a Java 6 issue.

Additionally, `HandPanel.java` used `java.util.function.Consumer<Card>` (Java 8), a method reference `this::repaint` (Java 8), and a lambda in a `@Override` method (Java 8). `GameBoardPanel.java` used `this::repaint` (Java 8).

## Fix

### MainWindow.java

1. Moved toolbar construction (which initializes `statusLabel`/`passButton`/`playCardButton`) **before** `handPanel.setOnCardSelected()` callback capture, so the fields are definitely assigned before the anonymous inner class closes over them.
2. Replaced lambdas with anonymous inner classes: `passButton` action, `playCardButton` action, `onStateUpdate` `invokeLater` callback.
3. Replaced the `stream().filter().max(Comparator.comparingInt())` chain in `playSelected()` with a plain for-loop finding the highest-influence non-human player.
4. Replaced `new ArrayList<>()` diamonds with `new ArrayList<Card>()` in `HandPanel`.

### HandPanel.java

1. Added `CardSelectedListener` interface (package-private, Java 6-compatible) to replace `java.util.function.Consumer<Card>`.
2. Changed field type, setter param, and callback invocation from `Consumer<Card>` / `.accept()` to `CardSelectedListener` / `.onCardSelected()`.
3. Replaced `this::repaint` method reference with `new Runnable() { run() { repaint(); } }`.
4. Replaced lambda in `MouseAdapter` override with a body block.
5. Removed unused `java.util.function.Consumer` import, added explicit `MouseAdapter`/`MouseEvent` imports.

### GameBoardPanel.java

1. Replaced `this::repaint` method reference with `new Runnable() { run() { repaint(); } }`.
