## The defect

Commit 07cb1fd (B5-0329) added an "assistant status overlay" inside the
active-conflict banner block of `GameBoardPanel.paintComponent`. The overlay
was fabricated content:

- **Invented personas:** "Ambassador — advisor on diplomacy/intrigue",
  "Lokai-Commander", "Refer-Consultant", "Strategy-Analyst",
  "Sanction-Interpreter". None of these names, nor any "assistant" concept,
  exists in the model (grep for `assistant` across `b5ccg/src/b5ccg/model/`:
  0 matches).
- **Fake task references:** entries cite "B5-0325 F9"–"B5-0325 F13"; B5-0325
  is Human Join UI and defines no F-numbered findings at all.
- **No rulebook basis in code:** rulebook §IV "Your Ambassador's Assistant"
  (rulebook lines 486–488) defines a character-rank mechanic — rotate the
  assistant to give the ambassador +1 Diplomacy/Intrigue/Leadership while
  rotated, or −1 influence on a later sponsorship that turn. Nothing in
  `model/` or `engine/` implements rotating an assistant, the +1 bonus, or
  the −1 sponsor cost, so no rotated/boost *status* exists to display.
- **Rendering corruption:** the overlay set an 8pt Monospaced font and never
  restored it before the banner title drew, so the CONFLICT title rendered in
  the overlay's font instead of SansSerif-Bold-14.

Displaying invented game entities in the player-facing UI is worse than a
missing feature — it teaches players rules the game does not have.

## The fix (one file, +4/−20)

- Deleted the overlay block (label, font, persona array, draw loop).
- Left a short comment explaining what stood there and why it was removed,
  so the deletion is self-documenting in the source.
- Banner font restored **structurally**: the SansSerif-Bold-14 `setFont` now
  directly precedes the title `drawString` (no stray font state between).
