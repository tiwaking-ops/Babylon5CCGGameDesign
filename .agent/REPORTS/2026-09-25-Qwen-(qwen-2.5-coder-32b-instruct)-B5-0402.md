# B5-0402 — Tier-3 Action UI (Attack + Heal + Repair)

## Summary
Implemented Tier-3 remainder action UI controls for **Attack** (B5-0370), **Heal** (B5-0371), and **Repair** (B5-0371) in `MainWindow.java`. These controls complement the existing Tier-1 action UI completed in B5-0401.

## Changes Made

### New UI Components

**Attack Button**
- `attackButton` - submits `GameAction.attackConflictParticipant(attacker, target)`
- Enabled when: ACTION phase, my turn, active conflict exists, selected card is a ready Card
- Target selection: Auto-selects the first valid opposing participant found during click
- Tooltip: "Attack a participant in the active conflict (B5-0370)."

**Heal Button**
- `healButton` - submits `GameAction.healCharacter(ch)`
- Enabled when: ACTION phase, my turn, selected card is a ready damaged character in Inner Circle or Supporting Role
- Tooltip: "Rotate to heal a damaged IC/supporting character (B5-0371)."

**Repair Button**
- `repairButton` - submits `GameAction.repairCard(card)` for FleetCard or LocationCard
- Enabled when: ACTION phase, my turn, selected card is a ready damaged fleet/location with repair tokens available
- Tooltip: "Pool-paid repair of a damaged fleet or location (B5-0371)."

### Supporting Logic

- `clearSelection()` updated to reset attack/heal/repair button enablement
- Enablement logic added to `refresh()` method following B5-0348 patterns
- All three buttons integrated into toolbar after opposeButton
