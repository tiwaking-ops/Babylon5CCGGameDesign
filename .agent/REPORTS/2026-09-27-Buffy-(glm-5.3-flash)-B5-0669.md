## Deliverable

Headline findings, all measured this pass (my own greps and section reads):

1. **Premise confirmed:** `civil war` and `unrest` both return 0 occurrences
   over `b5ccg/src` — neither the state machine nor the unrest axis exists.
2. **Structural finding (the correction that matters):** the seeding row
   inferred an expansion gate; the section headers show Dual Races (:956) and
   Civil War (:990) both sit under §VI Additional Rules (:741) with no
   expansion gate. The real gate is **multi-faction play**: a dual race
   requires more than one player faction of one race, and
   `TensionMatrix.raiseTension` no-ops on `source == target`, so a same-race
   tension slot cannot even be expressed today. The prerequisite slice
   (RaceIdentity / Home-Alternate factions) is *larger than R13 itself*.
3. **Collapse rule stated:** R11 (substrate), R12 (steady-state) and R14
   (Psi Corps needs a Human-race faction to exist) are **not separately
   seedable** — all four need the identical split architecture.
4. **Card-data gate:** `event_declaration_of_war` is a title-only collision
   with the :992 trigger (text: round-long Military conflict reward); "unrest"
   appears only in `enh_babylon5_unrest` (raises Influence costs). Zero pool
   cards invoke any of these axes; engine slices are implementable-now with
   synthetic fixtures, card-visible behaviour is data-gated.
5. **Design delivered:** unrest as a per-faction 1–5 int (never a tension
   axis); same-race tension in a parallel `SameRaceTensionMatrix` (B5-0358's
   race-level matrix untouched); split as `RaceIdentity → Set<FactionIdentity>`;
   rounded-up-average merge; `:996` end-war targeting rule. Divergences
   flagged, not fixed: engine tension clamp 0–5 vs rulebook 1–5; two distinct
   `Faction` types per the TensionMatrix header warning.

## Reusable lesson

A state machine whose actors cannot exist is not a backlog item — find the
identity prerequisite that makes its actors possible, and size *that*; the
machine itself is then a sequel, not a starting point.
