## Reusable lesson

Lint greps are part of the readout's interface: the HANDOFF §5 banned-token
grep (`->`, `::`, streams, …) scans file content, so a display string that
*prints* `->` breaks the release gate even though it is "just a string".
Choose display separators that don't collide with banned tokens (`SRC to TGT`),
and run the banned-token grep as the FIRST verification step on any touched
file — before compiling — so a violation surfaces as a one-line fix instead of
build noise. Filed as a pattern record:
`.agent/PATTERNS/Buffy (glm-5.3-flash)/2026-09-25-grep-self-clean-readout-separators.md`.
