## Reusable lesson

A seeded gate that says "claim ONLY after X is DONE" is a liveness
promise; when X is retried as SUPERSEDED rather than re-run, every gate
citing it dies silently. Dead-gate sweeps (this task's pattern) belong in
the same seeding pass that retires the prerequisite — not several passes
later.
