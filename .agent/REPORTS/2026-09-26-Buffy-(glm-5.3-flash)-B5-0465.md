## Delta classification

1. **Stall "10 → 20 percent": NOT CONFIRMED.** The 20% figure comes only
   from D-0462b (non-matching method, single seed, no report). The
   seed-matched D-0462a reproduces the baseline exactly: 1 TIMEOUT in 10,
   in the SAME seed-105 game-2 slot as the baseline's lone timeout —
   seed 105 is the chronically slow game, not a new pathology. The QUEUE
   0464..0467 note echoed this figure; that echo is retracted by this
   triage. No balance slice is indicated by stall.
2. **Initiator win 87 → 64/67.5 percent: REAL DRIFT, BAND-NORMALIZING.**
   D-0462a measures 67.5% (54/80). Binomial noise at n=80 is ±10pp, so
   the move from 87% exceeds noise — but the direction matches the
   mechanism and the landing point is INSIDE the historical band (0408:
   58%; guide §7 cites 58-71%). Mechanism with file and line evidence:
   resolveConflict awards the initiator only when support strictly
   exceeds opposition, or opposition is zero
   (RulesEngine.java:306-309). 0453 raised war-declaration and
   location-play value (AIPlayer.java:617, :536), increasing initiated
   capture wars; opposing seats' outweigh-if-possible logic is unchanged
   (AIPlayer.java:132-138, B5-0343), so a larger share of initiated wars
   meets real opposition instead of walking through at opposition=0.
   Classification: designed-effect drift back toward the rulebook band,
   not a regression. Watch it, don't fix it.
3. **Promotions 4.9 → 3.2 per game: GAME-LENGTH ARTIFACT (mostly).** Mean
   game length fell ~10.5 → 8.4 rounds; per-round rate moved only
   0.47 → 0.38. Fewer rounds mechanically shrinks every per-game count
   (see pattern: explain-soft-drift-by-game-length). Not a promotion-path
   change; no promotion scoring was touched by 0453.
4. **Promotions-token question (in scope per row): ALREADY RESOLVED.**
   The 0409-era artifact (parser counted ": promotes " with colon; engine
   logs " promotes " without) was fixed; the current parser counts
   " promotes " (HeadlessMultiRoundTest.java:276) and the fix is pinned by
   comment (:29). The 0447 and 0462a promote figures are REAL counts, not
   parser zeros. The 0456 honesty note remains correct for pre-fix
   baselines only.
5. **agendas 0/10: parser artifact, NOW FIXED mid-flight by B5-0464** (the
   " sets agenda:" token gained its emitter in GameController; suite 398).
   Future baselines will show a nonzero agendas column — that is the
   counter starting to work, not behavior change.
