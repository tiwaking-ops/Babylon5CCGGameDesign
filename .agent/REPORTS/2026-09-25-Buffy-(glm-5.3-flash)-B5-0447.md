# B5-0447 — Post-timeout balance re-probe (B5-0444 runner)

## Verdict

Stall is no longer the norm: **9 of 10 games terminate naturally with a
winner** under the 180s cap (baseline: 0 of 5 at 60s). The B5-0422/0431
"stall is partly a labeling artifact" analysis is confirmed by the runner's
own terminator classification.

## Method

seeds 101,103,105,107,109 (two games per seed, seeds step 2 from the
default 42-lineage), EASY/MEDIUM/HARD/MEDIUM mix, full action set.
Execution only; zero source edits. 10 games = the runner's default N.

## Aggregates vs B5-0408/0409 baseline

* **Stall rate: 1/10 (10%)** vs baseline 5/5 (100%) — the headline change.
* **Terminating conditions:** 9 WINNER, 0 ROUND_CAP, 1 TIMEOUT. Natural
  termination spans rounds 4–16 (56–178s); the single TIMEOUT still fired
  at 15 rounds (matches 0422's prediction that some seeds stall pending
  the human's option-A ruling).
* **Win spread:** Beta 4, Alpha 2, Gamma 2, Delta 1 — no dominant seat;
  the EASY seat won 0 games directly but sits in 9/10 winning games.
* **Initiator win rate:** 69/79 initiated conflicts won (87%) vs baseline
  21/36 (58%). Small samples both; direction consistent with the B5-0309
  sides rule plus richer participation now that games run longer.
* **Action mix per game:** promotions 4.9 avg (baseline 0 — the B5-0321
  promotion path is finally exercised in real games); Build Influence 9.3
  (baseline 9.8); aftermaths 7.1 (baseline 4.2); agendas 0/10 (baseline 0).
* **AI anomalies:** zero agendas in every game remains unexplained and is
  NOT the old pass-bias stall (9 decisive games had ample rounds) — flagged
  for a future AI-scoring audit; report-only scope here. Promotions now
  fire (0.5–11 per game) with high seed variance.

## Reusable lesson

Long harness runs should be batched by seed with per-seed output lines, not
one giant invocation: batches keep each command inside execution time
limits, isolate a hang to one seed, and give per-seed rows that aggregate
cleanly into the report table.
