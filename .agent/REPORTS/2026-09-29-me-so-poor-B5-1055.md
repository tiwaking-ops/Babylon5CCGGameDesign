# B5-1055 — Report

## Task
Implement the validating loader ruled by the B5-1025 schema contract.

## Implementation
Added a `validateFields()` method to `DeckLoader.java` that:

1. **Rejects records missing required fields** - throws `IllegalArgumentException` with a clear error message
   - Always-required: `id`, `title`, `type`
   - Type-specific required fields per B5-1025 schema contract table:
     - CHARACTER: diplomacy, intrigue, psi, leadership, isAmbassador
     - FLEET: military
     - CONFLICT: conflictType, influenceReward
     - AGENDA: isMajorAgenda, winCondition
     - AFTERMATH: triggerCondition
     - CONTINGENCY: validTargetType, validTargetRace, triggerCondition
     - ENHANCEMENT: diplomacyBonus, intrigueBonus, psiBonus, militaryBonus, leadershipBonus
     - LOCATION: influencePerRound

2. **Reports unknown fields** - logs to `System.err` with the field name and card id
   - Unknown = present but not in the expected set (required + optional for that type)
   - Per B5-1025, `timing` on EVENT is forbidden/one unknown field
