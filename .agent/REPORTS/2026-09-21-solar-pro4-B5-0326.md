# B5-0326 — Action-set UI part 1 (F3 core + F5)

**Date:** 2026-09-21  
**Agent:** solar-pro4 (solar-pro4:free)  
**Scope:** `b5ccg/src/b5ccg/ui/` only — `MainWindow.java`  
**Gates:** Java 6 grep clean, compile ✓, conformance 81/81 PASS, smoke PASS

## Changes

### F3 core — action-set toolbar buttons

Three new buttons added to the bottom toolbar (between Play/Initiate and the cost readout):

- **Sponsor** — calls `GameAction.recruitCharacter(selectedCard)` when a CharacterCard from hand is selected, ACTION phase, human's turn, and `RulesEngine.canRecruit` passes. Uses `GameAction.recruitCharacter` (the existing RECRUIT_CHARACTER factory) — no new model/method edits.
- **Promote** — calls `GameAction.promoteCharacter(ch, leader)` where leader is `findUnrotatedIC(human)`. Enabled when a supporting-role CharacterCard is selected, ACTION phase, human's turn, the card is ready (not face-down, not rotated), and an unrotated IC member exists.
- **Build Influence** — calls `GameAction.buildInfluence(leader)`. Enabled when ACTION phase, human's turn, `RulesEngine.canBuildInfluence(human)` (influence ≤ 9 + unrotated IC) is true.

All three use `MainWindow.this.controller` to reach the enclosing field from within the anonymous inner `ActionListener` classes (Java 6 requirement — no lambdas).

### F5 — cost preview readout

A `JLabel costLabel` placed between the action-set buttons and the conflict target selector. Displays a live cost preview when a card is selected during the ACTION phase:

- **Sponsor cost:** `rules.recruitCost(human, ch)` — shown when the selected card is in the human's hand and ready.
- **Promote cost:** `rules.promotionCost(human, ch)` — shown when the selected card is in the human's supporting role and ready.
- **Build Inf:** fixed text "Build Inf: -3 (+1 rating)" — shown when `canBuildInfluence` is true (not card-specific).

The label is cleared (`"  "`) when no card is selected, outside ACTION phase, or when the selected card doesn't match either condition. Trims trailing `"  |  "` separator.

### Enablement logic (refresh)

All three buttons follow the same per-phase pattern in `refresh()`:

```
actionPhase = (phase == GamePhase.ACTION)
button.setEnabled(actionPhase && myTurn && card-specific-conditions)
```

- Sponsor: card must be face-up (not face-down), not rotated, in hand.
- Promote: card must be face-up, not rotated, in supporting role, unrotated IC exists.
- Build Influence: `canBuildInfluence(human)`.

### No engine/model edits

Per B5-0326 scope (`ui/` only, read-only model/engine access), the implementation uses only existing public APIs:

- `GameAction.recruitCharacter`, `GameAction.promoteCharacter`, `GameAction.buildInfluence`, `GameAction.pass`
- `RulesEngine.canRecruit`, `RulesEngine.canPromote`, `RulesEngine.canBuildInfluence`, `RulesEngine.recruitCost`, `RulesEngine.promotionCost`
- `Player.getHand()`, `Player.getSupportingRole()`, `Player.getInnerCircle()`, `Player.getInfluence()`
- `GameState.getPhase()`, `GameState.getActiveConflict()`, `GameState.getHumanPlayer()`, `GameState.getActivePlayer()`, `GameState.isGameOver()`, `GameState.getRoundNumber()`, `GameState.getLog()`, `GameState.getPlayers()`, `GameState.getWinner()`
- `GameController.isWaitingForHuman()`, `GameController.getState()`, `GameController.submitHumanAction()`
- `Card.getTitle()`, `Card.getText()`, `Card.getCost()`, `Card.isRotated()`, `Card.isFaceDown()`
- `CharacterCard` (extends Card)

No new methods, fields, or types were added to `model/` or `engine/`.

## Notes

- The "Sponsor" button uses `recruitCharacter` (RECRUIT_CHARACTER) rather than a new `sponsorCharacter` factory, because B5-0326 scope forbids engine/model edits. The rulebook term "Sponsor" maps to RECRUIT_CHARACTER in the existing action model; the button label uses the rulebook term for player clarity.
- Cost values are all 0 today (no card data carries costs yet — B5-0311 C1 / B5-0323). The preview readout shows 0 for all cards until the data backfill; the plumbing is in place.
- `findUnrotatedIC` is a private helper that scans `Player.getInnerCircle()` for the first non-rotated character, used by both the Promote button handler and the Build Influence button handler.
