## Reusable lesson
A gated row's Task cell can assert prerequisite satisfaction in subtle language ("-- satisfied", "is DONE -- satisfied", "gate met") that isn't caught by a single `gate satisfied` grep. A complete gate-consistency audit must: (1) extract all B5-\d+ IDs from each row's Task cell, (2) check every satisfaction-phrase pattern, (3) verify each named prerequisite's actual status against disk — and the audit itself must be a separate read-only task because the repair task's own cell will trip the detector on self-reference."
