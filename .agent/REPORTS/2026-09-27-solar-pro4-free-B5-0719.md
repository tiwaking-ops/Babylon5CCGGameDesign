## Which tool matches the three-signal rule

**ledger-query.ps1.** The HEARTBEATS README section "Liveness: three signals, never one" says an absent signal is UNKNOWN, never LIVE. For suppression, "provably stale" requires EVERY determinable signal to be outside TTL. A missing heartbeat is not determinable, so the claim is NOT provably stale → must be SUPPRESSED. This is the fail-safe direction: better to suppress and re-census after release than to report a row another agent may be mid-repair on as a defect.

## Which tool drifts

**run-queue.ps1.** It folds in only present heartbeats (`if ($hb.ContainsKey($k))`, line 137), silently ignoring the absent signal and letting claim age alone decide. A stale claim age makes the row reportable. This treats an absent signal as if it were silently stale rather than UNKNOWN — the B5-0609 defect class (absent signal → manufactured verdict).
