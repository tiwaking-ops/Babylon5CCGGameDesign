## The trap in this task

The obvious discriminator - "is it green?" - **does not work here**, and that is the whole finding: **all
eleven exit 0** on the current green tree. Any classification done by name, or by "it passed when I ran it",
is decoration. The discriminator had to be read out of the code: the exit contract and the cost.

**Rule adopted:** a class is a GATE only if its non-zero exit means a defect. If a non-zero exit can also mean
"bad argument" or "harness broke", it is a PROBE, because wiring it turns an ordinary condition into a red
build.

### Why each PROBE is a probe (evidence, not taste)

* **ReportingTiebreakTest** - its 26 checks pass, but the live round-cap leg reads `NOT_APPLICABLE` on an
  ordinary run because the trigger needs 2+ players at 20+ influence and an ordinary run ends 0/4 there
  (B5-0350 row). The live check silently does not fire and the class still exits 0. 15.4 s is 7x the rest of
  the gate tier combined.
* **HumanSeatProbe** - its own B5-0482 header records that `Deck`'s constructor shuffle takes no `Random`, so
  hand contents cannot be made deterministic from the harness, and that a coverage gate was relaxed to soft
  for that reason. A class documenting its own non-determinism is reporting.
* **MultiRoundTest** - **no failure exit exists**: only `0` and `3`, and `3` is a deck-load / harness exception
  (lines 68, 74, 104). It prints aggregate statistics. A class that cannot say "failed" cannot gate.
* **StallSoakProbe** - its own last line reads `STALL-SOAK PROBE COMPLETE (classifications are reporting, not
  failures)`; `2` is a bad-argument exit, `3` a harness exception. 16.3 min.

### Determinism

No class is fully deterministic: `b5ccg/src/b5ccg/model/Deck.java:11-15` and `:42` use unseeded
`Collections.shuffle`. That argues **for** the gate tier - the 8-run sweep hit the real variance source rather
than a pinned one, and the gate classes were insensitive to it. I did **not** add seeding: that converts a
verifier false negative into a deterministic one (B5-0495 precedent) and needs a `model/` edit, out of scope.

## Reusable lesson

A harness's exit code is a contract, and a non-zero exit only means "defect" if the class has no other
non-zero exit; `exit 2` for a bad argument and `exit 3` for a harness exception are the two lines that most
often disqualify an all-green class from being a gate.
