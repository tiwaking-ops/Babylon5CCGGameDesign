## The criterion, stated so it is reproducible

Score = **R x S x P**, three integer factors 1-3, each read off a measurement, not
a preference. Any two agents running this get the same order.

* **R — reach.** Unregistered **in-play copies** (not corpus), tiered: 25 or more
  scores 3, 8-24 scores 2, 1-7 scores 1. How often the type reaches play.
* **S — silent or loud fallthrough.** The divergence an unregistered id causes at
  its dispatch site: 3 = silent (the printed effect simply never happens and
  nothing is logged), 2 = substituted (a *different* effect lands, and it is
  logged), 1 = covered generically (the effect already lands by another route).
  EVENT scores 2 because `applyPlayEvent` falls through to `p.drawCards(1)` with a
  log line, so an unregistered Event is **actively wrong** — the player draws a
  card instead of rotating a character. ENHANCEMENT scores 1 because
  `applyPlayEnhancement` already applies the JSON bonus fields by subtype, so the
  numeric part lands regardless of registration.
* **P — partial dispatch already present.** 3 = the type has an id-keyed table
  *and* a per-type dispatch site, so the next entry is an addition to an existing
  seam. 1 = no seam exists, and the type is not a coverage gap in the D15 sense.

## Which of the three dominated: **P**, decisively

* **P is the only factor that partitions the result.** It is binary and it splits
  the table cleanly: the top four all have P=3 (a table and a dispatch site already
  exist); the bottom five all have P=1 (no seam exists to extend). Every other
  factor splits the table along a different line.
* **R would have given the wrong answer at the top.** By in-play volume alone the
  order is CHARACTER 45, EVENT 39, CONFLICT 29 — CHARACTER first. But CHARACTER has
  **no id-keyed dispatch surface at all**; its printed abilities ("While Adira Tyree
  is in your Inner Circle, you may look at one opponent's hand") are a different
  feature (persistent triggered abilities), not a missing row in a table. Ranking it
  first would send the next agent to build a subsystem.
* **S is nearly constant and discriminates almost nothing.** Seven of nine types
  score 3. It is retained because it is the factor separating EVENT's
  actively-wrong fallthrough from the merely-absent one, and that distinction is
  worth having — but it moved no card across a tier boundary in the final order.
