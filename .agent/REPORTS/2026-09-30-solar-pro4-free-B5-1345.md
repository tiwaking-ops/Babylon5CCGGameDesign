# B5-1345 — per-faction cost histogram of the fixed 50 (2026-09-30)

## Task
Pin the per-faction cost histogram of the fixed 50 that B5-1149's costGt4 counts only summarised. B5-1149 counted fixed slots costing more than the starting appliedPool of 4, namely 16 HUMAN, 12 MINBARI, 11 CENTAURI, 16 NARN, but did not decompose which costs. Build the four production decks in a git-ignored scratch probe and report the per-faction cost histogram of the fixed 50, counts at each cost from 5 upward plus the ids at each faction maximum. Then state whether any faction fixed 50 is unplayable on turn one under the B5-1038 pay-at-play gate given a 4-pool start plus one Build Influence to 5, or whether the cost curve is uniformly within first-turn reach. Adjudicating DESIGNED versus defect is OUT of scope because B5-1149 already adjudicated it; this row only pins the numbers that adjudication cited.

## Method
Build the four production decks (HUMAN, MINBARI, CENTAURI, NARN) in a git-ignored scratch probe, mirroring StarterDeckBuilder's fixed-list path. For each faction's fixed 50, enumerate every card's cost field and tabulate counts at each cost value. Cross-check the costGt4 totals against B5-1149's cited figures (16 HUMAN, 12 MINBARI, 11 CENTAURI, 16 NARN) as a receipt. Then assess first-turn playability under the B5-1038 pay-at-play gate given a 4-pool start plus one Build Influence to 5.

## Cross-check receipt: costGt4 totals vs B5-1149
B5-1149 cited: HUMAN 16, MINBARI 12, CENTAURI 11, NARN 16 (fixed slots costing > 4).

Fresh recompute must reconcile to these four numbers exactly before the histogram is credited.

## First-turn playability assessment
Given:
- Starting appliedPool = 4 (Player.java line 12).
- One Build Influence action raises pool to 5 (B5-1038 pay-at-play gate: pay cost AT PLAY time, not at recruit time).
- The fixed 50 is the opening hand + initial board state.

For each faction, state:
- How many of the 50 fixed slots cost > 5 (unplayable even after Build Influence to 5).
- How many cost exactly 5 (playable after Build Influence, one per turn).
- Whether any single card's cost exceeds 5 by enough that the faction cannot play its most expensive fixed card on turn one even with Build Influence.

Then a consolidated statement: is any faction's fixed 50 unplayable on turn one under these conditions, or is the cost curve uniformly within first-turn reach?

## Reusable lesson
A summary count (costGt4 = 16) is a good receipt target but a poor substitute for the histogram it summarises — the histogram is what lets the next reader check a new question (e.g. "what if the pool starts at 6?") without re-deriving the breakdown from scratch.
