## Semantics chosen (and why)

* **D1**: Won/Lost play conditions now always follow the *initiator's* outcome
  for every player, per rulebook "Aftermath Cards": a conflict in which a
  non-initiator side gains more support is "lost by the Initiator", and that
  is what gates Won/Lost aftermaths for everyone. A winning *opposer* now
  plays "Lost"-condition aftermaths (before the fix he played "Won" ones).
  Kept `canPlayAftermath`'s signature; the param is now documented as
  initiator-won and the only caller (GameController) was updated, so no
  stale call sites exist.
* **D3**: added `if (t.contains("PSI") && conflictType != PSI) return false;`
  Before, a PSI-triggered aftermath (`WON_PSI` etc.) was eligible on *any*
  conflict type because no branch rejected it. Current card data contains no
  PSI-triggered aftermaths (grep: 0 matches), so no data change is needed.
* **D8**: rulebook Draw Round Step 3 — "may not reshuffle; must discard one
  Inner Circle character; if he cannot, he loses the game". The old
  `recycleDiscard()` loop is gone. Penalty applies per *required draw* that
  finds the pile empty (a 2-card draw on an empty deck costs two characters —
  that is the honest reading of "when he must draw at least 1 card" per
  card not drawn; noted as an interpretation, see DECISIONS.md). Ambassadors
  are never candidates. Forfeit is surfaced via `Player.hasForfeited()`;
  `RulesEngine.checkVictory` returns the last non-forfeited player when
  exactly one remains. Draw pile integrity is preserved: discarded IC
  characters go to the discard pile.
