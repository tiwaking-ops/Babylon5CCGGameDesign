## Precision fixes worth carrying forward

Two reporting subtleties surfaced mid-probe, both corrected before close-out:

1. **Slot index is not path evidence.** First armed log labelled the withdrawn
   card `RANDOM-SLOT` from its index (50) alone — the arming row happened to
   append *after* the 50 real fixed slots, so index ≥ 50 there means "51st fixed
   slot", not random draw. The production `fixed count=51` line plus deck size
   61 is the path evidence; the deck-short guard and explicit fixedCount
   accounting disambiguate. Position alone cannot classify a slot.
2. **Overlay must shadow the canonical name.** A differently-named overlay
   resource is inert: `DECK_RESOURCE` is a compile-time constant, so the
   classpath trick works only if the shadow file carries the exact resource
   name the code loads.
