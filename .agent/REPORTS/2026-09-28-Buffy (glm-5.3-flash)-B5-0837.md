## Reusable lesson

**A containment line that does not match is a silent failure**: a gitignore
entry whose bytes do not exactly equal the target name (here, one stray
trailing ASCII colon) reads as done while containing nothing. Only a
negative-control exit code — `git check-ignore -v` on the real path — proves
a match; never trust that the line you wrote matches the thing you aimed at.
