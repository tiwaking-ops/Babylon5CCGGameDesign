## What was delivered

`.agent/tools/suite-coverage.ps1` — strictly read-only (writes nothing; no
side effects outside stdout):

- Enumerates every `check(` site and extracts the section-code **first
  argument regardless of quoting style**: straight double, straight single,
  curly open/close pairs (the B5-0594 gap-5 variant quoting), backtick, and
  a first argument sitting on a following line.
- Letter-suffixed and hyphenated codes (AMT2, AGL-AI, STH-AI…) are reported
  verbatim — no pattern filter that could silently drop a code.
- Per-code totals and a per-test-method breakdown.
- Optional case-insensitive `-Code` filter with line + method attribution.
- An **UNPARSABLE counter that names every site** whose first argument is not
  a string literal, so "0" for an existing code is visible as a broken parse
  rather than authority.
- Reads ONLY the first string argument of each `check(` call — never the
  label or condition arguments, never narrative fields (the B5-0609 defect
  class: reading ids/coverage out of prose).

## Reusable lesson

An instrument that can silently report zero for an existing thing is worse
than no instrument: build the broken-parse counter into the first version and
verify it against a fixture where the answer is known — including one site
that must fail to parse — before trusting any number it prints about the real
thing.
