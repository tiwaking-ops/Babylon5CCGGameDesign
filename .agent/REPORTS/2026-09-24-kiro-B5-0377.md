# B5-0377 Completion Report

**Task**: Implement AI scoring for agenda lifecycle (DISCARD_AGENDA, REPLACE_AGENDA, REVEAL_AGENDA) and contingency lifecycle (PLAY_CONTINGENCY, REVEAL_CONTINGENCY) actions in MEDIUM and HARD difficulty tiers.

**Status**: DONE

## Summary

Extended `AIPlayer.java` with scoring and legal-action offers for the 6 missing action types. All changes compile cleanly, smoke test passes (19 AI actions executed), and the implementation follows existing scoring patterns.

## Implementation Details

### 1. Scoring (MEDIUM tier)
- **REVEAL_AGENDA**: `agendaProximityScore(agenda)` — full proximity value since hidden agendas have no effect (:520)
- **REPLACE_AGENDA**: `agendaProximityScore(replacement) - 1` — proximity minus rotation cost
- **DISCARD_AGENDA**: `1` — low priority, rarely voluntary
- **PLAY_CONTINGENCY**: `2` — modest future-proofing value
- **REVEAL_CONTINGENCY**: `2` — same as PLAY (no additional value from face-up state)

### 2. Scoring (HARD tier)
- **REVEAL_AGENDA**: `agendaProximityScore(agenda)` — unchanged from MEDIUM
- **REPLACE_AGENDA**: `agendaProximityScore(replacement) - 1.0` — double version
- **DISCARD_AGENDA**: `0.5` — lower than MEDIUM (HARD more conservative)
- **PLAY_CONTINGENCY**: `1.5` — slightly lower than MEDIUM (HARD less speculative)
- **REVEAL_CONTINGENCY**: `2.0` — modest bump over PLAY

### 3. Legal Action Offers
Added offers in `buildLegalActions()` for:
- **DISCARD_AGENDA**: checks `canDiscardAgenda()` for revealed non-major agendas
- **REVEAL_AGENDA**: offers for face-down agendas via `canRevealAgenda()`
- **REPLACE_AGENDA**: offers replacement from hand when IC leader is ready
- **PLAY_CONTINGENCY**: offers from hand to any controlled host via `canPlayContingency()`
- **REVEAL_CONTINGENCY**: offers for face-down placed contingencies via `canRevealContingency()`

Added helper method `inPlayHosts(Player p)` returning all controlled cards (ambassador, IC, supporting, fleets, locations, groups, enhancements, agenda) for contingency host enumeration.
