## What was built

A standalone, Java 6 headless probe that runs N seeded games (mirroring the
HeadlessMultiRoundTest construction verbatim: same factions/difficulties,
StarterDeckBuilder pipeline with heuristic fallback, per-seat RNG seeding via
reflection, daemon game thread) and prints a per-seed table:

- rounds reached, terminator classification (WINNER / ROUND_CAP / TIMEOUT)
- winner name or none
- **winning condition** (LAST_STANDING / AGENDA_WIN / STANDARD_VICTORY /
  STATION_VICTORY / ENGINE_WINNER-unclassified) — re-derived post-game by
  mirroring RulesEngine.checkVictory's decision order, with condition 2 read
  through reflection on the engine's own `stationVictory` classifier so the
  label can never drift from the engine
- end-of-run influence standings + elapsed seconds

Exit code is nonzero **only on harness exceptions** (deck load failure,
construction failure) — a stalled/timed-out game is a reported
classification, not a failure, exactly as the row scope requires for the
B5-0577 soak to loop seeds without touching game logic.

Usage: `java -cp out b5ccg.engine.HeadlessStallSoakProbe [numSeeds] [baseSeed] [timeoutSec]`
or `HeadlessStallSoakProbe 62,44,51 [timeoutSec]` for explicit seed lists.
