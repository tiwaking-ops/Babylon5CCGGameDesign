# B5-0333: Cost on card face (F13)

## Summary

Added influence cost display to `HandPanel.drawCard()` so players can see
each card's cost render on its face in the hand.

## Problem (B5-0310 audit, F13)

Cards with non-zero influence cost (per B5-0323 plumbing) show no cost
in the hand panel. Players cannot tell at a glance which cards cost
influence to play. B5-0310 §Card-face audit: "Implementation plan: render
the cost value on each card face in HandPanel.drawCard; zero-cost cards
omit the label."

## Implementation

**File:** `b5ccg/src/b5ccg/ui/HandPanel.java`

Added a cost label in `drawCard(Graphics2D g, Card card, int x, int y, boolean selected)`,
placed between the faction line (y+37) and the stats section (y+50):

```java
int cost = card.getCost();
if (cost > 0) {
    g.setFont(new Font("SansSerif", Font.PLAIN, 8));
    g.setColor(new Color(220, 200, 100));
    g.drawString("Cost: " + cost + " INF", x + 3, y + 46);
}
```

Design decisions:
- Only rendered when `cost > 0` (zero-cost cards omit the label per spec).
- Uses warm gold color `(220, 200, 100)` to distinguish from faction (grey)
  and stats (green) — visually separate semantic channel.
- Font size 8 PLAIN, consistent with the faction line's visual weight.
- Positioned at y+46, between faction (y+37) and stats (y+50), in the gap
  left by the original layout.

## B5-0323 plumbing dependency

The implementation depends on `Card.getCost()` (B5-0323) being available.
Verified in tree:
- `Card.java`: `cost` field (default 0), `getCost()`, `setCost()` accessors.
- `DeckLoader.java`: parses optional `"cost"` key from JSON card data.
- All cards without a `"cost"` key default to 0 (no label shown).
