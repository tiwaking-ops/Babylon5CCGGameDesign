# B5-0325 — Human join UI (F1+F2)

## Summary
Wired the human-player join UI in `MainWindow.java` (the only file changed). Two
features landed, both reads of the B5-0322 engine API with NO engine/model edits.

## Changes
**File:** `b5ccg/src/b5ccg/ui/MainWindow.java` (full rewrite, 211 lines)

### F1 — Support/Oppose buttons
- Two new toolbar buttons ("Support", "Oppose") wire to
  `GameAction.joinSupport()` / `GameAction.joinOppose()` via
  `controller.submitHumanAction(...)`.
- Enabled whenever `state.getActiveConflict() != null` (any phase, any player's
  turn) — the human can join an active conflict regardless of whose turn it is.
- Disabled when no conflict is active (no false affordance).

### F2 — Conflict target selection
- New `JComboBox<String>` target selector, populated with non-human player names
  when a ConflictCard is selected in the hand.
- When a non-conflict card is selected, the selector is disabled and cleared.
- `playSelected()` uses `selectedTarget` if the human picked one; falls back to
  auto-target (highest-influence non-human) if the dropdown was never touched.
- After playing a conflict card, the selector is cleared and disabled.

### Callback semantics (F2)
- Selecting a conflict card in the hand → dropdown populated + enabled, status
  line says "Target: choose from dropdown".
- Selecting a non-conflict card → dropdown disabled + cleared.
- Dropping down and picking a player → `selectedTarget` set, play button
  re-evaluated.
- Playing any card clears `selectedTarget`, clears the dropdown selection, and
  disables the dropdown.

### Enablement rules
| Control     | Enabled when                                            |
|-------------|--------------------------------------------------------|
| Pass Turn   | `myTurn`                                               |
| Play/Initiate | `myTurn && selectedCard != null` (and no active      |
|             | conflict if a conflict card is selected)              |
| Support     | `activeConflict != null` (any turn)                   |
| Oppose      | `activeConflict != null` (any turn)                   |
| Target dropdown | `selectedCard instanceof ConflictCard` (human turn) |

### No engine/model edits
Only `b5ccg/src/b5ccg/ui/MainWindow.java` changed. The B5-0322 engine API
(`GameAction.joinSupport/joinOppose`, `GameController.processAction` cases,
`RulesEngine.canJoinConflict/executeJoinConflict`) is consumed read-only.
