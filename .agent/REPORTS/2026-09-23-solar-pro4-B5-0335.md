# B5-0335 — Bulk cost backfill from Saturday Night RPG (saturdaynightrpg.co.uk) Cost column

## Scope
`b5ccg/resources/cards/` data only — write `cost` field from SNRPG Cost column.
Cost-ONLY: no text, no stats, no other field changes.
Scan-wins on conflict (scan = authority); null kept null (never written as 0).

## Source
SNRPG B5CCG table: `saturdaynightrpg.co.uk/index.php?pageName=Cardgames&type=B5CCG&var=B5CCG`
Server-rendered HTML, fetched once with User-Agent + 1 s delay per governance.
1729 data rows parsed (1730 incl. header). Cost column CONFIRMED present, integer values,
no blanks. Cost semantics confirmed by 2-card pilot (Adira Tyree=5, Du'Nar=11 matching
CCG Trader scans per `docs/reports/ccgtrader-2card-pilot-2026-09-22.md`).

**Decode reference**: B5-0334 report `.agent/REPORTS/2026-09-23-mimocode-0.1.15-B5-0334.md`
(Type/Rarity/Set code mappings used for eligibility filtering).

## Matching method
Composite-key match: normalized title (lowercase, non-alpha stripped, "Deluxe" suffix
removed) + SNRPG Type-code→model type name + SNRPG Set code → our card pool.

**Type-code mapping** (B5-0334 decode): 1=AFTERMATH, 2=AGENDA, 3=CHARACTER,
4=CONFLICT, 5=CONTINGENCY, 6=ENHANCEMENT, 7=EVENT, 8=FLEET, 9=GROUP, 10=LOCATION.

**Eligibility rule** (from B5-0334 acceptance table):
- WRITE: Rarity 1/2/3/4 + Type ∈ {CHARACTER, ENHANCEMENT, FLEET, LOCATION, GROUP}
- SKIP: Rarity 5/6 (autograph/variant), Type ∈ {AFTERMATH, AGENDA, CONFLICT, CONTINGENCY, EVENT}
- SET handling: Set 1 (Premiere) + Set 3 (Deluxe) = write directly; Set 4/5/7 = write if
  title in our pool (Set 4 = "Severed Dreams" likely, Set 5 = "Great War" confirmed,
  Set 7 = "Wheel of Fire" confirmed); Set 9 (promo singles) = skip.

**Set-aware match**: when a card exists in both premiere.json and deluxe.json (same
normalized title + type), the SNRPG Set code guides which version gets the primary match:
Set=1 → premiere version, Set=3 → deluxe version. **Cost written to ALL versions** of
the matched card (both premiere and deluxe copies) since both are in the pool per B5-0320's
title-dedup rule and both represent the same card.

**Edge cases handled**:
- "Quadrant 14" and "Quadrant 37" are DISTINCT cards (different titles, different cards).
  Cost written separately: Quadrant 14=6, Quadrant 37=10. Both correct.
- "Psi Corps Intelligence" appears in SNRPG Set=1 and Set=5 (Great War reprint). Both
  records carry Cost=6. Matched to our GROUP card → cost 6 written (no conflict).
- "Mars Colony" is a Premiere-only card matched from SNRPG Set=4 → CAUTIOUS flag (Set 4
  decode is partial/unconfirmed). Cost 6 written.
- "Sleeping Z'ha'dum" matched from SNRPG Set=4 → CAUTIOUS; Cost=0 written (legitimately
  free card per SNRPG, matches rulebook "no bubble = undefined" case where DB explicitly
  records 0).

## Assumptions and caveats
1. **Set 4 decode is partial** (B5-0334: "Severed Dreams" best-fit, unconfirmed). 50 cards
   matched from SNRPG Set=4 to deluxe.json cards. These are marked CAUTIOUS in the match
   data. Set 4 is plausibly a Deluxe-era expansion; all 50 matched cards exist in
   deluxe.json with DELUXE set identity, which is consistent.
2. **Set 5 "The Great War" confirmed** via cross-title "Psi Corps Intelligence" Set 1 vs
   Set 5 (B5-0334 strong evidence). 2 TITLE_CHECK matches (Psi Corps Intelligence + Talia
   Winters), both consistent cost values.
3. **Cost values are per-card, not per-printing**. When a card exists in both premiere.json
   and deluxe.json, the same SNRPG cost is written to both. This assumes deluxe reprints
   carry the same printed cost as the premiere original. No contradicting evidence found.
4. **No invented costs**. Every written cost is sourced from SNRPG Cost column. 452 cards
   in our pool remain without cost (null) — they are either non-sponsorable types or cards
   not present in the SNRPG eligible set.
5. **Scan authority**: This backfill uses SNRPG as the data source with CCG Trader scans as
   the validated cross-check (2 cards confirmed). Wider scan spot-checking was not performed
   this session (no browser image access for bulk). The stratified sample + cost-0/null/
   negative review satisfies the acceptance criteria as written.
