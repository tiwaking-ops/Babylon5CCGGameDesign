# B5-0561 — Human-seat probe victory-window hardening

**Task**: Relax the winner-within-3-round-window hard check in HeadlessHumanSeatProbe.java to a soft-gate that reports but does not fail when the seeded game reaches no victory in the window.

**Finding (B5-0557)**: HeadlessHumanSeatProbe fails 1/37 on the winner check — a seed-dependent flake where the game does not reach a rulebook victory within the 180s probe window. Reproduced identically on committed HEAD (b5eabc89) without B5-0556 changes, confirming the root cause is the harness window, not an engine regression.

**Fix**: Replaced the hard `check("game produced a winner (rulebook victory)", state.getWinner() != null)` at line 225 with a soft-gate patterned on B5-0482's agenda-lifecycle precedent:
- On winner found: `mark("NOTE: no rulebook victory within 3-round window ...")` records it as informational.
- On no winner: prints `[INFO] No winner within probe window — seed-dependent, not an engine regression (B5-0557/0561 soft gate)` and the probe continues.

The probe still exits 0 when all other checks pass; the winner information is preserved for diagnostic value.

**Scope**: `b5ccg/src/b5ccg/engine/HeadlessHumanSeatProbe.java` only — no game-logic or suite edits.

**Reusable lesson**: When a probe check fails due to a timeout window rather than an assertion on behavior, soften the check to an informational mark rather than deleting it — the information (did the game end in time?) is still useful for diagnosing slow seeds, and the B5-0482 soft-gate pattern already established this for agenda-lifecycle coverage.
