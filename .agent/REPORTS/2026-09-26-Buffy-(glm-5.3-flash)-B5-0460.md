   the comment early and broke the build twice before the cause was
   spotted. Pattern filed.
2. First heal fixture used 2 damage on a greatest-ability-2 character:
   `Card.reconcileDamage()` neutralized it (correct engine behavior),
   which set the neutralizedThisTurn heal lock and failed 3 checks. Fixed
   by damaging 1 (below threshold). Lesson: fixtures must respect the
   reconcile threshold. Pattern filed.
