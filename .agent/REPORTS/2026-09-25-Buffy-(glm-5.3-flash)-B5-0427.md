## Reusable lesson

A paint-thread fixture must hand every player a non-null `Deck` — drawZone's
deck-count line NPEs otherwise (real games always deal; a scratch GameState does
not). More generally: when verifying a UI readout headlessly, assert BOTH the
marker's presence where it should be and its absence where it must not be
(face-down opacity here), and snapshot the at-war set inside the readout itself
(`getAtWarPairs()` returns a fresh copy) so paint never iterates engine state.
