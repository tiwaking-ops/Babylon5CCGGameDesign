## Design decisions

1. **Paint-thread safety.** `Conflict.getCommittedCards(Player)` returns the
   *live* internal list. A commit landing mid-paint would throw
   `ConcurrentModificationException` on the paint thread if iterated
   directly, so the readout snapshots each participant's cards into a new
   `ArrayList` before iteration.
2. **Deterministic order.** Lines iterate `state.getPlayers()` (stable)
   rather than `getParticipants()` (HashMap keySet, order unstable across
   JVM runs).
3. **Geometry.** Lines start at `+62` below the banner center, below the
   B5-0316 line at `+46`, inside the banner's center gap; zone rendering is
   untouched (B5-0330a geometry lesson applied).
