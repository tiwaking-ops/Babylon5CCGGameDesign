# B5-0349 — Seeded multi-round runner

## Task
NEW harness file only (`b5ccg/src/b5ccg/engine/HeadlessMultiRoundTest.java`), seedable Random, N-game summary (conflicts initiated/won/lost, promotions, Build Influence uses, aftermaths played, agendas set, winner); no game-logic edits.

## Implementation
- Single new file: `b5ccg/src/b5ccg/engine/HeadlessMultiRoundTest.java` (346 lines, Java 6)
- Seeds AIPlayer.rng via `java.lang.reflect.Field` setAccessible(true) so identical seeds reproduce identical games
- Runs N complete games headless via `GameController.runGame()` on daemon threads; 60s per-game timeout
- Parses the game log post-run for action stats: `: INITIATE_CONFLICT:` (initiated), ` won by ` (resolved, initiator matched to winner), ` builds influence:`, `: promotes `, ` plays aftermath:`, ` sets agenda:`
- Prints: header (game count, seed), per-game round/elapsed/winner/stats, aggregate totals, per-player wins, per-game winners, SEEDED RUN COMPLETE
- CLI usage: `java -cp b5ccg/out b5ccg.engine.HeadlessMultiRoundTest [numGames] [seed]` (defaults: 10 games, seed 42)

## Verification
- `compile.sh` (RUN_TESTS=1): 176/176 conformance + smoke PASS, exit 0
- `java -cp b5ccg/out b5ccg.engine.HeadlessMultiRoundTest 1 42`: runs to completion, prints full summary, exit 0
- Java 6 construct grep on engine/: clean

## Notes
- Game may stall when all AI players pass consecutively (known EASY AIPlayer limitation — `chooseActionOnEmptyHand()` returns PASS most of the time; MEDIUM/HARD do not help when they cannot afford actions). Harness correctly reports `winner: stalled` and does not hang — 60s per-game timeout fires and the thread is abandoned.
- Stats counts are log-derived, not model-derived, so they reflect what was logged during play. Conflict init/won/lost counts are cross-referenced (initiator from the most recent `: INITIATE_CONFLICT:` line before each ` won by ` line).
