## Reusable lesson

A nondeterministic probe (like HeadlessHumanSeatProbe with wall-clock scheduling) can produce flaky results across identical invocations. Before diagnosing failures, run multiple censes; one failing run may be noise, not signal. When the test harness uses no seeded RNG, aggregate across runs rather than treating single-run failures as defects.
