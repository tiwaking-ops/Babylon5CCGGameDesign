# B5-0387 — Fleet-class population plan

## Result

This report maps every `FLEET` JSON record in Premiere and Deluxe to the 20-value vocabulary from B5-0353. It is a data-population plan only: no JSON or source files were edited.

The cross-check found 80 records: 44 in `premiere.json` and 36 in `deluxe.json`, across 44 unique titles. There are 36 title-matched reprint pairs and 8 Premiere-only titles. This corrects B5-0353's stated 40/40 set split and its claim that Deluxe has the same full class distribution: Expeditionary and Homeworld appear only in the current Premiere data. Every record maps to a class; the Deluxe Fleet of the Line ID has a repeated `fleet_` segment and maps to the same class as its Premiere counterpart.

The 20 values are uppercase strings, matching the existing `fleetSubtypes` vocabulary style. Both records in each title-matched pair receive the same value. The runtime title-dedup behavior selects one copy; the plan preserves values on both source records for consistency.

## Data-owner decisions for this plan

1. **Battle granularity:** keep `FIRST_BATTLE`, `SECOND_BATTLE`, and `THIRD_BATTLE` as three separate classes. Their IDs and printed class labels distinguish them, so restrictions can name a specific battle fleet.
2. **Non-Aligned classes:** assign `DRAZI`, `IPSHA`, `MARKAB`, and `VREE` to their respective fleet records. They are fleet classes, not missing faction classifications; keep `fleetClass` populated rather than null. A participation rule can include one by naming its value.
3. **Unique classes:** use `FLEET_OF_THE_LINE` and `WARLEADERS` for those title families, including both set records where present. A one-card class remains useful and well-defined; do not collapse it to null or to a faction class.

These are the explicit recommended data-owner resolutions requested by B5-0387. They settle the schema for the later population task; this report does not itself change canonical data.

## Method and verification

- Read-only parse of b5ccg/resources/cards/premiere.json and deluxe.json; selected type == FLEET, checked set counts, normalized the Deluxe de_ ID prefix for classification, and matched IDs against the B5-0353 classes.
- Cross-checked the vocabulary and Limited Strike values against the B5-0353 report and B5-0356 filter findings. Card text is not reproduced.
- Coverage: 80 fleet records, 44 Premiere, 36 Deluxe, zero unmapped, all 20 vocabulary values present, and 44 distinct titles.
- No build was run: this report-only task made no source or data changes.
