## Part 1 — the policy

Filed as **[2026-09-29-heartbeat-retirement-policy.md](docs/proposals/2026-09-29-heartbeat-retirement-policy.md)**
(`docs/proposals/`, proposal tier, confers no authority until adopted):

- **R1** retirement = archival, never deletion/rewrite: move byte-identical to
  `.agent/HEARTBEATS/_retired/`; registry untouched.
- **R2** retirable only when ALL of: mtime older than 24h (48 TTLs);
  payload agrees (`idle` or closed tombstone — never `busy`/`active` on mtime
  alone); no OPEN row / live claim / standing finding names it; performed
  under a claimed ledger row with the evidence note.
- **R3** afterwards a resolved-to-retired heartbeat is **UNKNOWN** for liveness
  — never LIVE, never STALE — the canonical README's no-heartbeat answer,
  which this proposal does not weaken.
- **R4** the no-heartbeat rule stays exactly as the README binds it.
- **R6** adoption path: proposal → HEARTBEATS README merge → DECISIONS entry.
