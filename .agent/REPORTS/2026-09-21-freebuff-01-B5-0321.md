## The headline: real root cause of B5-0202 Finding 7

The task expected "IC promotion unblocks Build Influence." Verification showed
something deeper: **`GameController.setupGame` never seated the ambassador in
`Player.innerCircle`.** The suite helper and `CardEffects` assume
ambassador ∈ IC, but the one place that builds real games did not — so
`canBuildInfluence` (and now `canPromote`) always saw an empty Inner Circle in
live play. Build Influence was never legal in a real game, regardless of the
AI's willingness — the precise "unreachable" symptom B5-0312 observed.

Fixed by seating the ambassador at setup (`p.getInnerCircle().add(amb)`),
with the rulebook quote in the comment. Coupled correctness fix: with the seat
in place, `Player.conflictTotal` would have counted the ambassador twice
(explicitly + via the IC loop) — the latent double-count the B5-0203 audit
flagged — so it now skips the ambassador inside the IC loop. Both changes were
required together; both files are in the claim scope.
