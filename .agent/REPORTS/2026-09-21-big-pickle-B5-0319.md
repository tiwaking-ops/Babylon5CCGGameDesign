# B5-0319 - Real Premier starter decks

**Agent:** big-pickle (opencode/big-pickle) | **Date:** 2026-09-21 | **javac:** 1.8.0_292
**Scope:** `b5ccg/src/b5ccg/engine/`, `b5ccg/resources/decks/`, `b5ccg/src/b5ccg/Main.java`

## What changed

- **NEW** `b5ccg/src/b5ccg/engine/StarterDeckBuilder.java` - builds each race's
  printed Premier starter deck: 50 fixed cards (from the sourced advisory lists)
  + 10 random uncommons/rares, per `BABYLON5_CCG_RULEBOOK.md` ("Starter Decks").
  API: `build(Faction, List<Card>)`, `buildForFaction(Faction)`, `isAvailable()`,
  `findAmbassador(List, Faction)`, `setRandomSeed(long)`.
- **NEW** `b5ccg/resources/decks/premiere-starter-decks.json` - 187 flat rows
  `{deck, id, count}`; all ids verified against `premiere.json` (all FIXED,
  all PREMIERE); each deck sums to exactly 50.
- **CHANGED** `DeckLoader.java` - added `public static List<Map<String,String>>
  loadFlatObjects(String)` (reuses the existing tolerant tokeniser); widened
  `splitObjects` from `private` to package-private.
- **CHANGED** `Main.java` - `buildFactionDeck` delegates to `StarterDeckBuilder`
  with the legacy heuristic as fallback; the deal loop pins the race ambassador
  to the draw-pile top.
- **CHANGED** `HeadlessSmokeTest.java` - `buildFactionDeck` delegates the same
  way; the B5-0313 quota passes remain only for the heuristic fallback (the real
  fixed lists already contain conflicts + an agenda).

## Interpretation recorded (DECISIONS.md)

The 10 random cards are **distinct Premiere UNCOMMON/RARE cards playable by the
faction** (race-loyal + NEUTRAL + ANY), excluding the fixed 50. Draw is unseeded
in play and seedable in tests. The printed physical deck's "random 10" has no
source-level ordering, so a uniform distinct draw is the chosen model.

## Limits / open items (not defects of this change)

- The rulebook also mentions a fifth "Opposing Factions" deck; the sourced lists
  cover only the four race decks, so `StarterDeckBuilder` covers four factions.
- The 10 random uncommons/rares pool composition is an interpretation, not
  sourced (logged above); revisit if a printed source emerges.
- Deluxe decks are out of scope; the builder emits Premiere cards only.
