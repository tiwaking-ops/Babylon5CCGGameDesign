## The defect

The committed B5-0330 note renders at `cy + 58`, but mini-cards occupy
`cy .. cy+64` (`drawMiniCard`: small card h=64) and the stats baselines sit at
`cy+48` / `cy+56`. The "(+ N more)" text (8pt) therefore draws over the first
card's stats inside the card rectangle. The note only renders when a row
overflows, so the collision fired every time the note was visible — the fix
target state itself. (The B5-0330 report describes the position as "directly
below the last rendered card row"; it is inside the band.)

## Fix (one file, +20/−17)

- New shared helper `overflowNote(Graphics2D g, int hiddenCount, int x, int y0)`:
  renders "(+ N more)" at `y0+80` — below the `y0..y0+64` card band, clearing
  the border stroke (y0+62..64) plus descender clearance; no-op when
  `hiddenCount <= 0`. Also de-triplicates the draft's three copy-pasted blocks.
- Three call sites replaced: Inner Circle (`p.getInnerCircle().size() - icDrawn`),
  fleets (`p.getFleets().size() - flDrawn`), groups+locations
  (`glTotal - glDrawn`).
