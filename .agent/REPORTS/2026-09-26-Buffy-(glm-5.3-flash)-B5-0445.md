# B5-0445 — Playtest-guide station-hooks addendum (close-out report)

## Status

DONE.

## What was done

Added a B5-0445 addendum to §4 (board-readout paragraph) of
`docs/playtest-guide.md` documenting the B5-0437 station-influence card hooks:

1. **Capture source**: winning a LOCATION_TARGET war (first capture) raises
   human-side station influence by +1 and sets `stationSourceFired = true`.
   Recapturing a suppressed location restores effects but yields no station gain
   (recapture = restoration, not a source).
2. **Vorlon presence-bleed**: when a Vorlon player holds captured locations at
   the round boundary, vorlon influence gains +1 and sets the marker. Shadow
   presence-bleed is NOT wired (no Shadow faction in the enum, B5-0354).
3. **Decay sink**: if no source fired this round, all three ratings decay -1.
   The no-source guard means one source protects all three from decay.
4. **Marker lifecycle**: `applyEndOfRoundStation` runs BEFORE `advanceRound`
   (which resets the flag).
5. **Condition-2 / Shadow-War**: Shadow War triggers at influence >= 20;
   station victory condition 2 is suppressed when Shadow War is active
   (verified by HeadlessStationVictoryTest, B5-0382).
6. Updated suite count from 373 to 387 (B5-0437 STH x14 + B5-0436 D6/D7).
7. Updated status header and description date to 2026-09-26.

Playtest-guide station-hook documentation should reference the specific engine
method (`applyEndOfRoundStation`) and the specific probe (`HeadlessStationVictoryTest`)
so playtesters can verify the claims. The "373 suite count" in older guide
