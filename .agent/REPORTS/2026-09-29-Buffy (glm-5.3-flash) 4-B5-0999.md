## Reusable lesson

**A block reason that quotes the absence of a file dies when the file dies, and
nothing in the ledger knows it — a gate recorded as prose must be re-censused by
hand the moment the quoted artifact changes state.** The admin release opened
two gates and told everyone so in DECISIONS.md, yet both rows still read BLOCKED
six hours later because no tool re-evaluates row prose; the release note's own
instruction ("B5-0969 should be re-checked the same way") was the only thing
that carried the intent, and it needed a claimed row to become real.
