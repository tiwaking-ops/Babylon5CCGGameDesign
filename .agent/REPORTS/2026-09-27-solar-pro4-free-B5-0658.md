# B5-0658 — sixth suppression rule for census-crosscheck

**Scope:** `.agent/tools/census-crosscheck.ps1` only  
**Gate:** compile.bat green (no Java source touched); census-crosscheck exit 0 on live tree; exit 1 on fixture  
**Result:** DONE

## Change

Added a sixth comparison rule `suppression` to `census-crosscheck.ps1` that replicates each census tool's own `Get-CensusSuppression` verbatim and diffs the per-row suppression verdicts.

- **Get-Suppression-R** replicates `run-queue.ps1` Get-CensusSuppression (lines 73-137): two-signal (claim + heartbeat), falls back to claim age when no heartbeat exists for the owner.
- **Get-Suppression-L** replicates `ledger-query.ps1` Get-CensusSuppression (lines 160-230): three-signal (claim + heartbeat + report), suppresses immediately when no heartbeat exists for the owner.
- Both built from verbatim logic copies; report index for L side, heartbeat index for R side, both keyed through their respective `Get-NormName` copies.
- Diff loop runs after the main `$allIds` construction, comparing per-row suppression verdicts.

**No edits** to `run-queue.ps1` or `ledger-query.ps1`. No src or resources edits. No commit.

## Reusable lesson

A suppression rule that only one tool computes is invisible to the cross-check; the cross-check must replicate each tool's own suppression logic verbatim and diff them, because the two copies are identical by construction and review but not yet by instrument — and the divergence surface (missing-heartbeat handling) is exactly the class that silently un-suppresses a live-repair row.
