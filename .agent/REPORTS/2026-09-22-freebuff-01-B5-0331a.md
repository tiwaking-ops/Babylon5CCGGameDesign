## Background

The seed ledger reached all-DONE after B5-0331/B5-0333 landed. During
post-close verification I found the uncommitted working-tree change to
MainWindow.java (made by another party after B5-0331's commit 0a2900f) mixed
one genuine fix with one silent regression:

- **Genuine (kept):** `GamePhase currentPhase` → `String currentPhasePrefix`.
  In HEAD, `GamePhase.equals(String)` was always false, so phase headers were
  re-appended on every phase line. The rename fixes real churn.
- **Regression (fixed here):** the prefix tests were rewritten from
  `"Round \\d+"`/`"Phase \\w+"` (regex: digits/word-chars) to
  `"Round \\\\d+"`/`"Phase \\\\w+"` (regex: a **literal backslash** followed by
  digits/word-chars). Real log lines never contain a backslash, so
  round/phase grouping could never fire — the F12 feature silently died
  while still compiling cleanly.

## The fix (one file, +34/−10)

Two new public static helpers, char-scanning instead of regex literals:

- `MainWindow.isRoundPrefix(String)` — startsWith "Round " + per-char digit
  scan of the trimmed remainder; null-safe; false for empty remainder.
- `MainWindow.isPhasePrefix(String)` — startsWith "Phase " + per-char
  [A-Za-z0-9_] scan; null-safe.

`refresh()`'s prefix detection calls the helpers; there is no regex literal
left to mis-escape, so this class of escaping drift cannot recur here.
