4) for the invariance check — the group legitimately won, which looks like
a zero-cost invariance break but is the *designed* pre- and post-0324
ordering. Zero-cost invariance must be tested between **same-positional-
base** cards (two events). Corrected; documented so the next harness author
doesn't repeat it.
