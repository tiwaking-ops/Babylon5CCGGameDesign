# B5-0201 — headless smoke test (engine/)

Agent: `freebuff-01`. Toolchain: `javac 1.8.0_292` (`javac -version`).

## Scope touched

* Added `b5ccg/src/b5ccg/engine/HeadlessSmokeTest.java` (new file, 262 lines).
* No existing file was edited; no game logic changed. `git status --porcelain`
  shows only the new harness plus this agent's claim/heartbeat files.

## What the harness does

1. `DeckLoader.loadBothSets()` — both JSON sets off the classpath; fails if the
   result is empty.
2. Builds four all-AI `Player`s (HUMAN/MINBARI/CENTAURI/NARN) with 60-card
   faction decks and 4-card opening hands; `AIPlayer` difficulties EASY, MEDIUM,
   HARD, MEDIUM.
3. Runs one full round through the real `GameController.runGame()` on a daemon
   thread with a counting `GameStateCallback` — no Swing/GUI, no human input
   path (`waitForHumanAction` is never reached because no player is human).
4. Asserts: no exception in the loop, round completed inside a 120 s budget,
   every player took at least one logged turn, the UI callback fired, decks and
   hands are intact.
5. Asks each `AIPlayer.chooseAction()` for a decision on the live state and
   checks any chosen card is in hand and playable by that faction.
6. Exits 0 on pass, 1 with a stack trace/loud message on any failure.

## Commands and results

* `sh b5ccg/compile.sh` → `✓ Build successful`, 34 source files, `-source 6
  -target 6`, only the expected bootstrap-classpath warning (exit 0).
* `java -cp b5ccg/out b5ccg.engine.HeadlessSmokeTest` → exit 0:
  `829 cards` loaded; round 1 completed in ~18.7 s; 31 AI actions, 36 UI
  callbacks, 63 log lines; 4/4 live AI decisions legal; `SMOKE TEST PASSED`.
* Negative control (classes copied without `cards/` resources) → exit 1 with
  `FileNotFoundException: Resource not found: /cards/premiere.json` (fail-loud
  path confirmed).
* Java 6 construct grep on the new file (`->|::|stream()|computeIfAbsent|
  @FunctionalInterface|try (`) → 0 matches.

## Observations (no fix applied)

* Round wall-clock is dominated by `GameController`'s hard-coded `pause(600)`
  per AI action; the 120 s budget is deliberate headroom.
* `applyGenericCardPlay` draws a replacement card for `EventCard`, so a hand that
  becomes all Events can in principle keep a player acting indefinitely; the
  harness reports this as `engine appears stuck (phase=ACTION)` instead of
  hanging. Did not reproduce in this run — route to B5-0202 if seen.

## Note on the harness's first failure

The first run failed on the harness's own logging assumption (`GameState.log()`
prefixes entries with `[R<n>] `); fixed in-harness before the passing run. This
is recorded so a later reader does not mistake it for an engine defect.
