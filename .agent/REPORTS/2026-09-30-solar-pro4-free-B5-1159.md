## Probe-design correction (first draft was broken)

The first probe draft set the ambassador via `setAmbassador()` but did NOT place the card in the hand. `findAmbassador()` (called by setupGame) searches `p.getHand()` — so the seat block was skipped and the IC stayed empty, producing a false breakage (12/16 fails). The corrected probe places each ambassador IN THE HAND before calling `setupGame()`, matching the real game flow (deck → drawCards → ambassador in hand → setupGame → findAmbassador finds it). The corrected probe passes all 16 asserts.

This is a reusable lesson about read-only probes: a probe that sets a field directly (setAmbassador) without reproducing the setup path that populates the dependent state (the hand) will report a false breakage. The probe must drive the real setup path or reproduce its prerequisites exactly.
