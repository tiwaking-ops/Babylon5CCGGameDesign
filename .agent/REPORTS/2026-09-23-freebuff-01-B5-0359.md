## Honesty corrections made during verification

The guide deliberately describes the engine **as it is**, and verification
caught two places where a drafted sentence would have lied:

* **Immediate resolution.** My first draft described the rulebook's
  Conflict/Resolution round split; the code resolves a conflict inside the
  `INITIATE_CONFLICT` handler. §3 now states the deviation explicitly and
  asks playtesters for feedback on how it feels.
* **The human join gap.** `resolveCurrentConflict`'s join loop contains
  `if (p.isHuman()) continue;` — the Support/Oppose buttons enable while a
  conflict is on the board but a human click cannot commit. The control
  table now says so plainly (pointing at B5-0345 #5), with the
  mandatory-participation exception (B5-0336) noted.
