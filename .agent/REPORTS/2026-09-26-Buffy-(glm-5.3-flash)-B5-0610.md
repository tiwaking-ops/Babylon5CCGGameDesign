## Finding 1 — the NON_ALIGNED thin field is a data-coverage gap, not an identity error

The rulebook is explicit that the identity is correct: §IV (:476) —
"'Neutral' is not a race … 'Non-Aligned' IS a race name"; the Great War
addendum (:878) — "The Great War introduces the League of Non-Aligned Worlds
as a new faction … Cards loyal to this race are designated as 'Non-Aligned'".
So NON_ALIGNED as a *race value* in the data is rulebook-faithful (and the
D13 fix in `Faction.isPlayableBy` already matches it).

Why only 4 cards: the League was *introduced by The Great War* (:208 — the
premier edition has four player races). The repo's two files are Premiere +
Deluxe; the full League card pool belongs to Great War-era releases that are
**not in the data**. The four League fleets shipped cross-set (usable by any
faction with a League alliance), which is why they appear in both files while
dedicated League characters/agendas appear in neither. Conclusion: **the
engine's card pool cannot currently support a playable League faction** — not
because of a data error, but because the League's own cards were never
seeded. Supporting evidence: `StarterDeckBuilder` builds only the four majors
(B5-0319), and `GameController` setup seats exactly HUMAN/MINBARI/CENTAURI/
NARN; the League-specific setup rules (:884 — no single starting ambassador,
player chooses any Non-Aligned species ambassador, second species ambassador
in the opening hand, unrest begins at 2) are unmodeled. This is a
**rulebook-faithful gap**, listed as such — no fix asserted here.

## Finding 2 — set parity is structurally sound

Zero ID overlap via the `de_` convention; zero intra-file duplicates; all
premiere records carry `set: PREMIERE` (post-B5-0318 deluxe carries DELUXE);
proportionally deluxe tracks premiere (CHARACTER 0.75x, FLEET 0.82x, EVENT
0.89x) with no type inverted. The one thin ratio is LOCATION.

## Finding 3 — the Status Tracker is a component, not an unimplemented card

Rulebook §IV (:468–470) documents the Status Tracker as a physical component
"Enclosed with the Great War Starter Decks" (the "Politics Tracker Sheet")
tracking tension, unrest, and non-player-forces influence. It is not a playing
card and correctly appears in **neither** JSON set. Engine analog: tension and
station/shadow/vorlon influence ratings are modeled as engine state (B5-0528
tensions, B5-0340 station), which is the right home — a "StatusTracker card"
would be a modeling error. Verdict: **component**; no data action warranted.

## Finding 4 — LOCATION at 8 in deluxe is plausibly intentional, flagged

LOCATION is the thinnest deluxe/premiere ratio (0.62x; all other types 0.75–
0.89x). Locations are scenario-space cards; a smaller deluxe print run is
plausible design intent, but with no Great-War-era set manifest in the repo
(C5 from the B5-0311 audit still stands) this cannot be verified — flagged,
not resolved.

## Reusable lesson

When a rulebook-named race looks under-represented in the data, check the expansion history the rulebook itself records before suspecting the data — a thin field can be the correct footprint of a set the repo never carried, and the audit's job is to separate identity errors from coverage gaps.
