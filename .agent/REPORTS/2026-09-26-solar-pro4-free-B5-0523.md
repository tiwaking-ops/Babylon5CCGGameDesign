## Background

The B5-0506 SHN engine path (CardEffects.applyPlayEnhancement with explicit-target
ENHANCEMENT_CHARACTER branch) grants each `bonusFor` value per-stat into the victim
registry. The shunned card's printed text says "loses 2 from all stats" but the JSON
carried `militaryBonus: 0`, so the Military penalty was never applied — the card
penalized everything except Military.

## Reusable lesson

When a printed "all stats" text and a per-stat JSON model disagree, fix the data
field only and verify against the existing per-stat conformance fixture. Do not
assume "all" maps to a single aggregate — check each stat column individually.
