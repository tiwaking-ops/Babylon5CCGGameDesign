# B5-0328 — Split Play/Initiate button (F4)

**Date:** 2026-09-21  
**Agent:** solar-pro4 (solar-pro4:free)

**Gates:** Java 6 gate clean, compile ✓, conformance 81/81 PASS, smoke PASS

## Summary

F4 ("Play / Initiate" button conflates two distinct rulebook actions) from the
B5-0310 UI audit is resolved. The single "Play / Initiate" toolbar button is
replaced with two separate, clearly labelled controls:

- **"Play Card"** — plays a non-conflict card from the human's hand
  (`GameAction.playCard(selectedCard)`).
- **"Initiate Conflict"** — initiates a conflict with a selected conflict card
  (`GameAction.initiateConflict(selectedCard, target)`).

Both buttons are created in the constructor, added to the toolbar, and wired
to `playSelected()` which dispatches on `instanceof ConflictCard` exactly as
the prior single-button path did. The human now sees which action will be taken
before pressing.

## Phase-appropriate enablement (F4 + F6 combined)

The split buttons implement the phase-aware gating called out in F4's
description ("phase-appropriate enablement"). `refresh()` computes:

```
phaseAllowsAction = ACTION || CONFLICT_RESOLUTION || AFTERMATH || DRAW
```

and enables exactly one of the two buttons based on card type and phase:

- **Conflict card selected, no active conflict:** only "Initiate Conflict"
  enabled (when `myTurn && phaseAllowsAction`).
- **Conflict card selected, active conflict already running:** both buttons
  disabled (can't start a second conflict — matches prior behavior).
- **Non-conflict card selected:** only "Play Card" enabled (when
  `myTurn && cardSelected && phaseAllowsAction`).
- **SETUP / END_ROUND phases:** both buttons disabled (no human actions legal).

This directly closes F4 (two distinct actions, clearly separated) and
reinforces F6 (phase-aware gating beyond "my turn") from the B5-0310 audit.

## No engine/model edits

Pure ui/ readout + wiring change. Reuses the existing `playSelected()` dispatch
and `GameAction.playCard` / `GameAction.initiateConflict` factories. No new
model types, no engine changes, no AI changes.
