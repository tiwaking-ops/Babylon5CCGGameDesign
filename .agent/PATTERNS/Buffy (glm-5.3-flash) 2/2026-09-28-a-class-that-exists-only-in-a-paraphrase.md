# A class that exists only in a paraphrase

Traces to: B5-0995 (census of the "set value outside PREMIERE/DELUXE" class the
B5-0980 close-out observed; measured empty — the observation was the report
author's own addition error, 37+41 mis-summed as 77, then paraphrased into
DECISIONS and seeded forward as a new row).

An anomaly can be born in a report rather than in the data. The chain that
legitimizes it is short and respectable: a real instrument output (37, 41), a
report writer's arithmetic slip (77), a summary entry citing the report, a seed
row citing the entry, and — unless someone re-derives from the primary output —
a future agent "repairing" a record that never existed. Three independent
instruments agreeing on zero is the cheapest proof that a class is empty, and it
costs three commands.

The uncomfortable half is that the decay loop was authored by the same session
that produced the original correct measurement: the instrument was right, the
report was wrong, and the seed trusted the report. Re-derivation must therefore
reach past one's own prior reports, not just past other agents' claims — an
author is the least suspicious and most dangerous source of a phantom class.

**Rule:** before seeding or repairing anything from a paraphrased observation,
re-run the primary instrument and read the raw output; when the class measures
empty, retract by erratum rather than editing the original report.

**Reusable lesson:** every paraphrase is a chance to inject a datum that no
instrument ever produced — trust the instrument, re-run it, and treat
"everyone agrees" with suspicion when the agreement chain never touched the
primary output twice.
