# Reusable lesson — B5-0697 (solar-pro4:free)

**Claim-file absence is necessary but not sufficient.** The race between two agents both measuring the same ID free inside the same window is real and has bitten this repo before (B5-0622: an agent held two claims on rows another agent had already closed). The re-read of the candidate row immediately after creating the claim file — confirming it still reads OPEN — is the only atomic check that catches this. Skip it, and you hand a BLOCKED/DONE/VOID/SUPERSEDED row to a worker who cannot complete it through this file.

**Correct behavior:** create claim → re-read row → if not OPEN, delete claim, do not work, note in heartbeat/ledger. A non-OPEN claim is an orphan; release it, do not work it.
