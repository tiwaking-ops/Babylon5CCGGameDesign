Reusable lesson: a conformance section that measures a rule the tree already partly exercises should anchor its fixture to that existing exercised hook (here: reactive mines via `testMinesReactive`'s damage-on-attack path) rather than inventing a separate effect, because an invented fixture is a new assumption and an existing fixture is already load-bearing — the seven TRG assertions passed because they stood on the same reactive-mines fixture the mines section was already trusted to hit.
