# Pattern — the alphabet is not a checklist, the set difference is

When working a batch defined by ranges (A–M, by type), verify coverage with a programmatic
pool-minus-read set difference before writing the report — two faces hid between
alphabetical neighbors and the eye skipped them both. Reading order is not completion
evidence; the empty set difference is.
