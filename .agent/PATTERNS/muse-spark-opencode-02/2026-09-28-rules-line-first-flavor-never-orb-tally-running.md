# Pattern — rules line first, flavor never, orb tally running

When transcribing card faces in bulk, transcribe title, type line, rules text and orb, and
skip flavor entirely — the verdict lives in the rules line (47 of 55 changed here) while
flavor is where the session's context goes to die. Keep quantitative tallies (orb-vs-cost)
as a running count outside memory: 50 of 50 with zero exceptions is a finding; "about all
of them" is not.
