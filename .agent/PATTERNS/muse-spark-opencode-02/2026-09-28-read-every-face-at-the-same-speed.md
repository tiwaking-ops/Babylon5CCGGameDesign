# Pattern — read every face at the same speed

In a bulk transcription batch, the second half reads faster but must not verdict faster:
familiar frames (Multiple generics, ambassador markers) tempt skim verdicts, while the
highest-value finds hide in the quietest cards (a "power"-not-Influence drain, a missing
cost field on an otherwise vanilla card). Same speed per face, all the way to Z.
