# A prerequisite gate prevents a false green

When an execution-only verification names an implementation prerequisite, a
blocked prerequisite is a gate-red result, not permission to run the old
behavior and report a misleading success.

**Reusable lesson:** preserve the gate and record the blocked evidence instead
of manufacturing a green receipt from an unmet precondition.
