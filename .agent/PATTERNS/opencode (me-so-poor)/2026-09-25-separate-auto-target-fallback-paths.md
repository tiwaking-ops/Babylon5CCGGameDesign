# Reusable Lesson — Separate Auto-Target Fallback Paths

When removing an automatic target fallback, audit neighboring action paths separately and name any retained fallback explicitly. A static search hit in a different dispatch path is not evidence that the target path still auto-selects, but it should remain visible as a follow-up.
