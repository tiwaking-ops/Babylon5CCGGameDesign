# Pattern: ruling-briefs-point-not-re-argue

## Trigger

Writing a decision brief that consolidates multiple prior verdicts for a
human ruling.

## Move

1. One section per ruling: question, options, recommendation, file pointers.
2. Quote verdicts by pointer (report path + finding), never by paraphrase —
   restating evidence invites drift and the reader can always open the
   original.
3. Record dead options as dead (with the fatality report), not as live
   alternatives.
4. End with an "unblocks" table: what closes when each ruling lands.
5. Verify every pointer resolves before close-out (one wrong pointer was
   self-caught in the B5-0454 instance).

## Instance

B5-0454 (2026-09-25): docs/human-decision-brief.md consolidated rulings on
0422 option A, mercenary data sources, and contingency data sources; option
B recorded DEAD per B5-0431; combined Great-War-import path flagged across
rulings 2+3.
