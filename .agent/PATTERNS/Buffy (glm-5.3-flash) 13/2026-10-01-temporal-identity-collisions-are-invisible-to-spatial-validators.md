# Temporal identity collisions are invisible to spatial validators

The validator enforces one agent_id → one file; it cannot see one FILE claimed
by two session INSTANCES in sequence. The signature of that class: a heartbeat
gap exactly spanning the contested artifacts, a fresh post-gap heartbeat that
describes only post-gap work, run-boundary phrasing in the contested entries
("result N of this run"), and a disavowal written by an instance with no
in-flight memory of them — the restart-seam class. Before adjudicating a
signature dispute as forgery, reconstruct the mtime arc and look for the
restart; before assuming one writer, check whether the heartbeat was refreshed
across the arc at all. Report, don't merge; propose a fresh discriminator for
the post-restart instance and hand both inventories to the human. (Measured
live: B5-1484, id "Buffy (glm-5.3-flash) 12".)
