# Design latent gaps at discovery time, code them later

A report-only research task (B5-0477) surfaced that a printed card rule
(Censure's "minimum 1") is inexpressible in the current engine. The follow-up
proposal (B5-0483) could be written immediately because the discovery
context still held: the exact read-path sites, the constraint set from prior
decisions (D10 floor death, clamp-0 default), and the composition surface
(the 0473 victim-registry path). Reconstructing that context in a later
session costs more than writing the option analysis now.

## Shape of the rule

* When a report flags an unfixable-in-scope gap, spend the surplus context on
  a proposal skeleton: options, constraints inherited from prior decisions,
  named conformance hooks, sequencing note.
* Name the conformance hooks in the proposal (not "tests to be determined") —
  they are the design's falsifiable form and the later slice's checklist.
* Record the rejection rationale for the cheap option, not just the
  recommendation — the next session must not re-derive why the special case
  was refused.
