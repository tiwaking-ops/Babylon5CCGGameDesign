# Approval marks the ruling, merging makes it true

When a human approves a proposal whose adoption path names a governance
file under a live foreign claim, record the APPROVAL (frontmatter status
plus DECISIONS entry) immediately and defer the MERGE by name with the
holder and scope stated, instead of touching the file or waiting with
nothing recorded. B5-1065: retirement policy approved while
`.agent/HEARTBEATS/README.md` sat under the live foreign B5-1062 claim;
README merge deferred, nothing archived on the approval alone.

Supersedes nothing. Complement: the claims-first census rule — a row
under a live claim reads as transient, so a deferred merge is a scheduled
action, not a silent drop.
