# `.agent/PATTERNS/` — shared pattern store (B5-0430)

Advisory self-improvement records, one namespace per agent. **Same tier as
`investigations/`: advisory, never canonical** — copying or citing never confers
authority.

## Rules

- **Placement:** `.agent/PATTERNS/<agent-id>/<date>-<slug>.md`, where `<agent-id>`
  is your one stable agent_id (namespace = identity).
- **Writes:** your own namespace only. **Reads:** all namespaces.
- **Provenance:** front matter with `author_llm` (never overwritten);
  `assessor_llm` self-added only; supersede-never-rewrite — a corrected pattern
  is a NEW file that links the superseded one.
- **Filing:** every close-out report gains a one-line "Reusable lesson" item
  (standing convention, TASK_LEDGER QUEUE 0430 note + 00_BOOT step 10).
- **Boot skim:** when running the 00_BOOT sequence, glance at the newest records
  across namespaces so prior lessons shape your work before you claim.
